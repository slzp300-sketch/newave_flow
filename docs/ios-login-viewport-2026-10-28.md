# iOS 로그인 보조 메뉴 및 카카오 인증 확대 복원

1.0.1(7) 실기기 피드백을 반영할 1.0.1(8) 후보 변경이다. 공개 1.0.0, Android·서버·DB는 배포하지 않는다.

- 일반 로그인은 기본값으로 바로 노출한다. 가상 자료 계정은 로그인 아래 ‘가상 자료 계정 이용’ 보조 메뉴에서 명시적으로 선택한다. 모든 사용자·배포 채널에 같은 메뉴를 제공하고 전체 기능/계정별 안내 링크를 유지한다. 가상 선택 시 폼 상단에 분리된 자료라는 안내와 일반 로그인 복귀 버튼을 표시한다.
- iOS 네이티브의 입력·선택·텍스트 영역은 최소 16px을 유지해 작은 입력창에 의한 자동 확대를 예방한다. 앱의 큰 글씨 설정은 유지하며 pinch zoom을 차단하지 않는다.
- 카카오 외부 인증을 시작하기 전에 입력 포커스를 해제하고 iOS 확대 복원을 준비한다. 인증 중 앱 복귀, 브라우저 취소, 인증 성공·실패 후 브라우저가 닫히는 경로에서 확대를 복원한다. 일반 앱 복귀는 사용자가 확대한 배율을 유지한다.
- viewport 보정 실패가 로그인 성공을 실패로 바꾸지 않게 한다. OAuth state/verifier 검증과 토큰·기록 저장 규칙은 유지한다.

로컬 프런트엔드 177개 검사와 iOS 웹 리소스 생성·소스 검증이 통과했다. 네이티브 검사에는 실제 packaged WKWebView의 16px 입력 크기, 처음 접힌 보조 메뉴·명시적 가상 선택, viewport 플러그인 및 일반 복귀 배율 보존 사례를 추가했다. 시뮬레이터에서 해당 검사를 통과한 뒤 TestFlight 업로드/교체 제출을 진행한다. 카카오 실계정·실기기의 브라우저 전환과 취소·다시 시도는 새 빌드에서 최종 확인이 필요하다.
