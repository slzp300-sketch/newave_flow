# iOS 버튼 반응 및 펼침 스크롤 개선

TestFlight 1.0.1(5) 이후 운영자 검수용 빌드 6에 포함할 변경이다. App Store 제출·공개 출시 및 Android·서버·DB 배포는 이 변경 범위에 포함하지 않는다.

## 변경
- 공통 AppMotion 영역의 버튼·메뉴 링크·펼치기에 동일한 눌림/복원 반응을 적용한다. 짧은 탭도 최소 120ms 동안 시각적 피드백이 남지만 클릭 처리나 저장은 기다리지 않는다.
- 한 세트의 위임 이벤트를 사용한다. 스크롤 이동 8px 초과, pointercancel, 창 비활성화, 컴포넌트 종료 시 피드백과 타이머를 정리한다. disabled·aria-disabled 및 보조 포인터는 반응하지 않는다.
- CSS 독립 scale을 이용해 기존 Framer Motion transform과 충돌을 피한다. 일반 버튼의 레이아웃 크기를 애니메이션하지 않는다.
- 공통 탭에서 즉시 칠해지는 버튼 배경 대신 기존 슬라이딩 선택 배경이 보이게 한다. 하단 메뉴의 중복 선택 테두리도 제거한다.
- TTS 선택/점수는 즉시 갱신하고 체크 표시는 짧은 CSS 확대·선 그리기로 전환한다. 일별 체크에 개별 JS 애니메이션을 추가하지 않는다.
- 기기 동작 줄이기 및 앱의 motion-reduced 설정에서는 눌림 축소와 애니메이션을 끈다.

## 확인
- 기존 프론트엔드 테스트 158개 + 공통 눌림 동작 테스트 4개 통과.
- 네이티브용 웹 빌드 성공. 기존 청크 크기 경고는 남아 있음.
- 가상 실제 컴포넌트: 버튼 클릭 즉시 횟수 갱신, 참석 선택, 탭 선택 배경, TTS 3회 연속 체크 후 15점 및 저장 완료 확인. 가로 넘침 없음.
- 동작 줄이기 강제 검수: scale 1, transition-duration 0s, 클릭 정상 실행 확인.
- 로컬 미리보기: http://127.0.0.1:5193/.verification/ios-candidate.html
- Android WebView와 iOS WKWebView를 고려한 공통 코드이나, 이번 수정의 실기기 체감 검수는 아직 하지 않았다. 새 TestFlight 빌드 설치 후 iPhone의 빠른 탭·스크롤 중 터치·탭 전환과 동작 줄이기 설정을 확인해야 한다.

## 펼침·접힘 스크롤 (사용자 최종 선택: 0.28초)
- 내용 높이와 스크롤에 같은 0.28초 사인 곡선을 적용한다. 내용이 다 열린 다음 별도로 이동하지 않고 함께 움직이며, 접힘도 역방향으로 진행한다.
- 짧은 내용이 이미 보이면 이동하지 않는다. 긴 내용은 첫 부분과 열기 버튼을 볼 수 있는 만큼만 이동하고 끝까지 강제로 내리지 않는다.
- 접으면 열기 버튼의 원래 화면 위치로 복귀한다. 버튼 위에 열리는 수정 폼, 다른 아코디언 전환, 빠른 재개방도 고려한다.
- 중간에 직접 터치·휠·방향키로 조작하거나 앱을 벗어나면 예약된 스크롤을 취소한다. 화면 초기 진입·오래된 클릭·무관한 버튼은 자동 이동을 유발하지 않는다.
- 모달 내부 펼침은 가장 가까운 스크롤 영역에서만 동작한다. 동작 줄이기에서는 필요한 위치 조정만 즉시 수행한다.
- 높이 애니메이션 바깥 래퍼와 안쪽 여백을 분리해 닫힘 마지막에 padding·border가 갑자기 사라지는 것을 방지한다.
- 공통 Collapse/CollapsePanel 적용 화면: TTS 편집·안내/주차 상세·학년, 출석/행사 사유·메모, 기도모임·교사회의, 프로필 수정, 홈 일정 상세·추가 일정, 계정 이력, 사진/신고 검토, 회의록/전도/일정 관리 폼과 상세, 일정 창 내부 시간·출석 설정.
- 홈 추가 일정은 먼저 보이던 다가올 3개를 유지하고 나머지를 버튼 아래에 펼친다. 접힘 버튼 자체가 추가 목록 밑으로 밀리지 않게 했다.

## 추가 검증
- 스크롤 자동 테스트 8개 통과: 양방향 점진 이동/원위치, 긴 내용, 포털 내부 스크롤, 사용자 개입 취소, 아코디언 전환, 초기/만료 클릭 차단, 동작 줄이기/정리, 위쪽 수정 폼 복귀.
- 실제 브라우저 가상 화면에서 펼침·접힘 높이와 스크롤 프레임을 측정했다. 0.38초 검수 후 사용자 요청에 따라 최종 0.28초로 변경했다. 내부 패널은 약 0.3초에 288px까지 펼쳐지며 창 스크롤은 1265px로 유지하고 내부 스크롤만 0→133px 이동했다.
- 전체 프런트엔드 검사 및 iOS용 웹 빌드 성공 여부는 최종 커밋의 CI에서도 다시 확인한다.
- iPhone 실기기에서 스크롤 끝 근처의 접힘, 큰 글씨, 키보드 표시, 빠른 연속 탭, 동작 줄이기 체감 확인은 새 TestFlight 설치 후 필요하다.
