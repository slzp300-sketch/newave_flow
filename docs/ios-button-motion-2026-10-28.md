# iOS 버튼 반응 개선 — 로컬 후속 수정

현재 TestFlight 1.0.1(5)에 포함되지 않은 후속 작업이다. 새 빌드 업로드, App Store 제출, Android·서버·DB 배포는 하지 않았다.

## 변경
- 공통 AppMotion 영역의 버튼·메뉴 링크·펼치기에 동일한 눌림/복원 반응을 적용한다. 짧은 탭도 최소 120ms 동안 시각적 피드백이 남지만 클릭 처리나 저장은 기다리지 않는다.
- 한 세트의 위임 이벤트를 사용한다. 스크롤 이동 8px 초과, pointercancel, 창 비활성화, 컴포넌트 종료 시 피드백과 타이머를 정리한다. disabled·aria-disabled 및 보조 포인터는 반응하지 않는다.
- CSS 독립 scale을 이용해 기존 Framer Motion transform과 충돌을 피한다. 레이아웃 크기를 애니메이션하지 않는다.
- 공통 탭에서 즉시 칠해지는 버튼 배경 대신 기존 슬라이딩 선택 배경이 보이게 한다. 하단 메뉴의 중복 선택 테두리도 제거한다.
- TTS 선택/점수는 즉시 갱신하고 체크 표시는 짧은 CSS 확대·선 그리기로 전환한다. 일별 체크에 개별 JS 애니메이션을 추가하지 않는다.
- 기기 동작 줄이기 및 앱의 motion-reduced 설정에서는 눌림 축소와 애니메이션을 끈다.

## 확인
- 기존 프론트엔드 테스트 158개 + 공통 눌림 동작 테스트 4개 통과.
- 네이티브용 웹 빌드 성공. 기존 청크 크기 경고는 남아 있음.
- 가상 실제 컴포넌트: 버튼 클릭 즉시 횟수 갱신, 참석 선택, 탭 선택 배경, TTS 3회 연속 체크 후 15점 및 저장 완료 확인. 가로 넘침 없음.
- 동작 줄이기 강제 검수: scale 1, transition-duration 0s, 클릭 정상 실행 확인.
- 로컬 미리보기: http://127.0.0.1:5193/.verification/ios-candidate.html
- Android WebView와 iOS WKWebView를 고려한 공통 코드이나, 이번 수정의 실기기 체감 검수는 아직 하지 않았다. 새 TestFlight 빌드 설치 후 iPhone의 빠른 탭·스크롤 중 터치·탭 전환과 동작 줄이기 설정을 확인해야 한다.
