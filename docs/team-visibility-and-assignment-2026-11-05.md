# 팀 조회·담당자 지정 및 찬양팀 학년 색상

사용자 요청: 모든 임원은 각 팀 화면을 볼 수 있고 일반 교사는 소속된 팀만 메뉴에 표시한다. 담당자 지정 화면을 미리보기로 확인하고, 찬양팀 명단은 기존 앱의 학년별 색상을 사용한다.

## 권한

- ADMIN·PASTOR·EXECUTIVE는 찬양팀, 중보기도팀, 새가족팀 조회가 가능하다.
- TEACHER는 해당 팀에 지정됐을 때 팀 메뉴가 보인다. 중보기도제목 본인 제출·공개 목록은 기존 교사 공통 기능으로 유지한다.
- 조회 확대와 수정 권한을 구분한다. 찬양팀 관리, 중보기도 접수·팀 전용 내용, 새가족 출결·과정 변경, 팀원 지정은 기존 담당 권한으로 제한한다.
- 비소속 임원은 찬양팀 불가 일정을 대신 제출할 수 없다. 새가족 화면은 조회 전용으로 표시한다.
- 임원 권한 해제·팀 해제·정지 상태는 서버에서 현재 계정으로 다시 판단한다.

## 지정 위치

| 대상 | 위치 | 지정 권한 |
| --- | --- | --- |
| 각 팀장 | 관리 → 임원 업무·조직도 → 직책 | ADMIN |
| 찬양팀 교사·학생 | 찬양팀 → 팀원 명단 → 팀원 지정 | ADMIN·PASTOR·찬양팀장 |
| 중보기도팀원 | 중보기도팀 → 팀원 명단 → 팀원 지정 | ADMIN·PASTOR·중보기도팀장 |
| 새가족팀원 | 새가족팀 관리 → 팀원 관리 | ADMIN·PASTOR |

새가족 명단에서 조직도로 지정된 팀장은 별도로 표시한다. 다른 조회자는 현재 팀장·팀원만 조회하며 전체 후보 명단과 변경 버튼은 받지 않는다.
