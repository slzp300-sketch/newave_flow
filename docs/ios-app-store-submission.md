# iOS App Store 제출 자료 초안

작성·공식 기준 확인: 2026-10-15. **현재 확인된 사용자 상태는 개인 개발자 가입 대기이며, 유료 결제·계정 활성화 여부는 미확인이다. 개인 명의 제출 적합성 확인, App Store Connect 앱 생성, TestFlight 업로드 및 심사 제출도 완료된 것으로 확인하지 않았다.** 아래 문구는 현재 코드에 맞춰 준비한 입력 초안이다. 실제 학생·교사 명단이나 비밀번호를 확인하지 않았다.

## 1. App Store Connect 기본 입력

| 항목 | 입력 초안 | 확정 조건 |
| --- | --- | --- |
| 기본 언어 | 한국어 | 앱 생성 시 선택 |
| 앱 이름 | 뉴웨이브 플로우 | 이름 사용 가능 여부 확인. 이름은 2~30자 |

| 기본 카테고리 | 생산성(Productivity) | iOS 등록 시 최종 선택. 보조 카테고리는 우선 비워 둠 |

이름·부제 규격은 [App information](https://developer.apple.com/help/app-store-connect/reference/app-information/app-information/), 설명·키워드·지원 URL·저작권·심사 연락란은 [Platform version information](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/) 기준이다. 지원 URL은 실제 연락 방법을 제공하는 웹페이지여야 하며 이메일 주소 자체를 URL 대신 넣지 않는다.

### 설명 — 붙여 넣을 초안

```text
뉴웨이브 플로우는 제자광성교회 뉴웨이브 청소년부 교사를 위한 사역 관리 앱입니다.

매일의 말씀과 기도, 주간 일정, 반 출석과 행사 참석을 한곳에서 확인하고 기록하세요.

나의 영성체크
말씀과 기도 실천을 체크하고 주간 점수, 달성률과 요일별 기록을 확인합니다. TTS 상세 화면에서 주별 기록과 개인 통계를 살펴볼 수 있습니다.

일정과 주간 체크
달력과 주간 체크에서 이번 주 할 일을 확인합니다. 일정 확인 상태, 기도모임 응답과 교사회의 참여를 기록할 수 있습니다.

반 출석과 공동 보고
담당 반 학생의 출석을 기록하고 반 공동 출결보고를 작성합니다. 반과 학생 정보는 계정 권한에 따라 확인하고 관리합니다.

행사와 공동 업무
행사별 접수 기간에 맞춰 참석 여부를 기록하고, 회의록과 전도 일정을 확인합니다. 관리 권한이 있는 계정에는 해당 업무의 관리 기능이 제공됩니다.

이용 안내
만 18세 이상 교사·사역 담당자를 위한 앱입니다. 가입 후 관리자의 승인이 필요하며 인터넷에 연결되어 있어야 합니다. 학생과 보호자가 직접 이용하는 앱이 아닙니다.

앱의 고객지원과 계정 삭제 요청 화면에서 문의 및 권리 행사 방법을 확인할 수 있습니다.

운영: 제자광성교회 뉴웨이브 청소년부
문의: slzp300@gmail.com
```

설명은 일반 텍스트 4,000자 이내로 입력한다. 현재 초안에 Apple 로그인, 오프라인 저장, 푸시 알림, 즉시 자동 탈퇴를 지원한다고 적지 않았다. 앱의 '알림' 메뉴를 OS 푸시 알림이라고 소개하지 않는다.

### 키워드 — 붙여 넣을 초안

```text
교회출석,교사일정,기도기록,말씀체크,행사참석,사역관리
```

공식 문서의 한도는 **100바이트**다. 위 문자열은 UTF-8 77바이트이며 쉼표 뒤 공백을 넣지 않았다. 앱 이름이나 타사 상표를 반복하지 않는다. 프로모션 텍스트와 앱 미리보기 영상은 선택 항목이므로 최초 제출에서는 비워 둘 수 있다. 첫 버전에는 '이 버전의 새로운 기능' 입력란이 제공되지 않는다. [버전별 입력 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/)

## 2. 심사 접근과 Review Notes

**아래는 최종 iOS 빌드로 검증한 후 사용하는 초안이다.** 기존 Android 준비 문서는 온라인 가상 심사 환경의 로그인·저장·격리를 확인했다고 기록하지만, 그 기록이 iPhone 최종 빌드 검증을 대신하지 않는다.

| 비공개 심사 입력란 | 값 |
| --- | --- |
| 로그인 필요 | 예 |
| 사용자 이름 | `<가상 교사 ID>@review.newaveflow.invalid` |
| 비밀번호 | `<현재 유효한 가상 교사 비밀번호 — 비공개 입력>` |
| 추가 관리 계정 | `<가상 관리자 ID>@review.newaveflow.invalid` / `<관리자 비밀번호 — 비공개 입력>` |
| 삭제 검수용 계정 | `<삭제 전용 가상 ID>@review.newaveflow.invalid` / `<삭제 검수 비밀번호 — 비공개 입력>` |
| 내부 사전검증 대상 API | `https://newave-review-production.up.railway.app/api` |

실제 로그인값은 승인된 비밀 보관 위치에서 확인해 App Store Connect에 직접 입력한다. 이 문서의 placeholder는 작동하는 계정이 아니다. 제출 기간 동안 계정이 만료되지 않고 승인·OTP·추가 연락 없이 접근할 수 있어야 한다. 삭제 검수 계정은 별도 준비해 기본 교사·관리 계정이 삭제되어 심사가 막히지 않게 한다. 심사 정보는 공개 스토어 설명에 넣지 않는다. [완전한 심사 정보 제공](https://developer.apple.com/help/app-review/before-submitting-for-review/complete-review), [심사 로그인 정보](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/)

### Review Notes — 검증 후 붙여 넣을 초안

```text
이 앱은 제자광성교회 뉴웨이브 청소년부의 승인된 성인 교사·사역 담당자가 사용하는 업무 앱입니다. 학생·보호자는 앱 계정을 만들지 않습니다. 주요 기능은 말씀·기도 실천 기록, 일정, 학생 출석, 반 공동 보고와 행사 참석 관리입니다.

제공한 계정은 실제 회원·학생 자료와 분리된 가상 심사 환경으로 연결됩니다. 로그인 화면의 아이디 칸에 제공한 이메일 전체를 붙여 넣으세요. 도메인이 자동으로 직접입력으로 바뀌며 '가상 심사 환경' 안내가 표시됩니다. 이메일·비밀번호 로그인으로 주요 기능을 검토할 수 있습니다.

로그인 후 이용수칙 안내가 나오면 내용을 확인하고 진행하세요. 홈에서 말씀·기도 체크와 개인 통계, 하단 일정에서 달력, 전체 메뉴에서 출석·행사 출석 체크·회의록을 확인할 수 있습니다. 관리 기능은 아래 추가 계정으로 로그아웃 후 다시 로그인하여 검토해 주세요.

추가 관리자: <관리자 이메일> / <관리자 비밀번호>
삭제 검수 전용: <삭제 전용 이메일> / <삭제 전용 비밀번호>

계정 삭제는 내 정보 → 회원 탈퇴·계정 삭제 요청에서 신청합니다. 접수 후 로그아웃되며 접수증으로 처리 상태를 확인합니다. 신청 접수와 실제 삭제 완료는 구분되며 담당자가 처리합니다.

Apple·카카오 인증 최종 구성 및 검토 방법: <제출 빌드에서 확인한 실제 상태와 필요한 검토 절차를 기재>
```

Review Notes는 최대 4,000바이트다. placeholder 교체 후 UTF-8 크기를 다시 확인한다. 소셜 인증 구성은 출시 빌드와 심사자에게 정확히 설명한다. 현재 Apple 로그인은 기본 비활성이며 가상 심사 서버는 Apple 키 설정을 허용하지 않는다. 이메일 가상 계정을 제공하는 것만으로 Apple 인증 전체를 검수할 수 있다고 적지 않는다. 실제 외부 인증의 검토 경로·필요 계정·시연 자료는 설정 완료 후 마련한다. [Apple 로그인 연결 현황](ios-apple-sign-in.md)

### 심사자 동선과 제출 전 검증표

| 순서 | 실제 화면 동선 | 확인할 결과 | 현재 상태 |

가입·승인 제한은 실제 서비스의 접근 조건이며 심사에서 숨기지 않는다. 리뷰 데이터만 가상으로 대체하고 기능을 심사 기간에만 바꾸지 않는다. 운영 계정이나 실제 학생 자료를 심사에 제공하지 않는다.

## 3. App Privacy 입력 준비

앱에서 서버로 계정·업무 기록을 보내 저장하므로 '데이터를 수집하지 않음'은 사용할 수 없다. 아래 **구현 확인**은 저장 구조·화면·정책에서 확인한 사실이며, App Store Connect 답변을 이미 제출하거나 Apple이 인정했다는 뜻이 아니다. 기본 목적 초안은 **App Functionality(앱 기능)**이고, 계정/학생 식별자와 연결되는 항목은 **사용자에게 연결됨: 예**로 준비한다. 광고 추적은 현 구현에서 확인되지 않았으나 출시 SDK·외부 제공자 점검 후 확정한다.

분류 이름은 [Apple 개인정보 유형·목적 안내](https://developer.apple.com/app-store/app-privacy-details/)를 사용했다. 종교적 신념은 Apple의 민감정보 예시에 포함된다. 입력이 선택이라는 이유만으로 라벨에서 제외하지 않는다. 학생·보호자처럼 계정이 없는 사람에 대한 정보도 검토 범위에 포함한다. 단말 주소록 권한이 없다는 사실만으로 수동 연락처·관계 정보 분류까지 확정하지 않는다.

로컬 `PrivacyInfo.xcprivacy`는 UserDefaults 사용 사유 등을 선언하는 네이티브 manifest다. App Store Connect의 수집·목적·연결성·추적 답변 전체를 대신하지 않는다. 광고 목적의 타사 데이터 결합, 데이터 브로커 제공 등 Apple의 tracking 정의와 단순한 계정 인증·호스팅을 구분한다. [개인정보 신고 기준](https://developer.apple.com/app-store/app-privacy-details/)

현재 방침 원본은 `frontend/src/content/privacyPolicy.js`, 시행일은 `2026-10-15`, `publicationReady=true`다. 정적 공개 HTML은 `frontend/tools/build-privacy-policy.mjs`가 만들며 `/privacy`로 연결된다. **2026-10-15 공개 지원·방침·삭제 안내의 브라우저 화면을 확인했다.** `/support`는 로그인 없이 고객지원·문의·삭제 안내·방침 링크를 표시했다. `/privacy`는 처음에 이전 PWA 캐시의 10월 14일 내용을 표시했으며, 앱이 제공하는 업데이트 버튼을 정상 적용한 뒤 시행일 2026-10-15와 계정 삭제 접수증·신고 보관 안내가 표시됐다. `/account-deletion`에서도 로그인 없이 삭제 범위·신청 방법·조회 코드 확인 경로·보조 문의 안내를 확인했다. 실제 신청·코드 조회·메일 전송은 실행하지 않았으며, 최종 iPhone의 삭제 전 과정과 제출 직전 세 URL 재확인은 별도 검수한다.

## 4. 연령 등급 질문 준비

**운영 대상 만 18세 이상과 Apple이 설문으로 계산하는 콘텐츠 등급은 별개다.** 현재 성인 교사용이라는 정책만으로 연령 확인 기능을 구현했다고 답하지 않는다. 가입 화면에는 관리자 승인 흐름이 있으며 정부 신분증/Declared Age Range API 등 연령 확인 구현은 확인하지 못했다. 최종 등급은 실제 콘텐츠와 현행 설문으로 산정한다. 필요한 경우 더 높은 등급 적용 선택지를 검토한다. 어린이 카테고리는 선택하지 않는 초안이다. [연령 등급 설정](https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating), [질문별 정의](https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions/)

| 질문군 | 초안·확인 필요 사항 |
| --- | --- |
| 광고·도박·현금/모의 도박·경품·전리품 상자 | 현재 코드에 해당 기능 없음. 제출 빌드·실제 운영 콘텐츠 대조 |
| 의료/치료 정보·건강 주제 | 진단·치료 기능은 확인되지 않음. 기도·상담 자유기록의 존재를 의료 기능으로 자동 신고하지 말고 실제 제공 콘텐츠 확인 |
| 사용자 생성 콘텐츠 | 보고서·메모·사진·회의록이 권한에 따라 공유됨. Apple의 '폭넓은 배포' 정의에 내부 업무 공유가 해당하는지 확인; 무조건 '없음'으로 작성하지 않음 |
| 메시지·채팅·소셜 미디어 | 전용 채팅·댓글·공개 피드는 확인되지 않음. 공동 게시·회의록·신고 흐름을 현행 정의와 대조 |
| 제한 없는 웹 접근 | 임의 URL 탐색 기능은 확인되지 않음. 회의 영상 등 실제 외부 링크와 iOS에서 열리는 방식을 검증 |
| 보호자 통제·연령 확인 | 관리자 승인과 접근 권한만으로 해당 기능이 있다고 답하지 않음 |
| 욕설·공포·약물·성적 내용·폭력 | 실제 가상 심사 콘텐츠와 운영자가 제공할 자료를 검토해 빈도 결정. 교회 앱이라는 이유만으로 전체 '없음'을 확정하지 않음 |

이용수칙·신고 화면이 구현돼 있으며 관리자 계정 정지·콘텐츠 처리 흐름은 별도 검증 대상이다. 이것만으로 모든 사용자 생성 콘텐츠 심사 요구를 충족했다고 표시하지 않는다.
