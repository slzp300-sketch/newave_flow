# 앱 전반 버튼 위치 점검 — 2026-11-06

## 범위와 상태

예배운영팀의 입력창 정리 기준을 다른 화면에도 적용해 달라는 요청을 반영했다. 로컬 수정이며 커밋·푸시·운영 데이터 변경·배포·스토어 업로드는 하지 않았다. 기존 예배운영팀 작업과 이전 미배포 변경은 그대로 유지했다.

## 반영 내용

- 공통 대화상자에 제목·스크롤 본문·하단 버튼 영역을 분리했다. 긴 입력창에서도 저장·취소·확인 버튼이 내용 아래로 밀리지 않는다.
- 보조 버튼은 왼쪽, 저장·확인 등 주 동작은 오른쪽으로 정리하고, 단일 주 동작은 전체 너비로 표시한다. 버튼 높이·간격·안전 영역을 맞췄다.
- 찬양팀 공통 입력창, 중보기도팀 제출·모임·팀원 지정, 임원 직책 지정, 전도 조 편성·일정, 일정 관리·일반 일정, 회의록 관리·교사 확인, 승인 후 반 배정, 날짜 범위 선택에 적용했다.
- 교사 권한 상세는 본문과 하단 닫기 버튼을 분리했다. TTS 주간 상세·아이콘 선택과 행사 출석 상세는 제목과 닫기 버튼을 유지하고 본문만 스크롤한다.
- 주간보고서 공통 항목·새가족 출석 저장줄·TTS 항목 저장줄도 간격과 버튼 폭을 정리했다.
- 저장 버튼이 본문 밖으로 이동한 경우에도 원래 입력 폼과 명시적으로 연결했다. 필수 입력 검사, 저장 중 잠금, 오류 표시를 유지한다. 일반 일정의 취소 버튼에는 비제출 타입을 지정했다.
- 저장 실패 안내는 하단에서 확인할 수 있고 작성 내용은 유지된다. 완료 알림은 하단 메뉴에 가리지 않도록 위치를 보완했다.

## 점검 방식과 결과

전체 입력·상세 대화상자와 주요 저장 영역을 소스에서 점검했다. 이미 적절히 분리된 학생·반 관리, 프로필, 투표 등의 배치는 유지했다. 부분 항목의 공유 설정처럼 해당 내용 바로 옆에서 처리해야 하는 동작은 문맥 안에 남겼다.

로컬 가상 자료 화면을 375×812 및 작은 320×600 크기로 확인했다. 실제 운영 계정·교사·학생 자료는 사용하지 않았다.

- 일정: 제목 필수 검사, 날짜 선택, 저장, 저장 실패 후 입력 보존, 계속 작성·버리기 동작을 확인했다.
- 전도: 여러 일정 등록, 교사 선택 후 조 이동을 확인했다.
- 중보기도팀: 팀원 선택창, 기도제목 필수 검사와 제출 완료를 확인했다.
- 회의록: 관리자 수정·저장, 교사 확인 완료를 확인했다.
- 가입 승인: 승인 후 반 배정 → 저장 완료까지 확인했다.
- 임원 지정·찬양팀 기간 등록·교사 권한 상세·TTS 아이콘 선택은 배치와 스크롤을 확인했다. 권한이나 운영 명단은 변경하지 않았다.
- 긴 본문에서 제목과 하단 버튼 유지, 가로 넘침 없음, 버튼의 폼 연결을 확인했다.
- 프런트 테스트 270개 통과. 웹 및 native 모드 웹 자산 빌드 통과. diff 공백 검사 통과. 기존 큰 번들 경고는 남아 있다.

실제 iPhone 키보드와 iOS 네이티브 빌드를 새로 검수한 것은 아니다. 이번 변경은 프런트 화면 구조에 한정되며 서버 변경·재배포는 하지 않았다.
