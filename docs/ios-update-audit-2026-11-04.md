## 마지막 대기 단계

- App Store Connect 로그인 세션이 만료됐다. 저장된 로그인 정보가 표시되지 않았고 iPhone 인증도 완료되지 않았다. 새 로그인 탭을 열어 사용자에게 직접 로그인을 요청했다. 암호를 채팅으로 요구하지 않는다.
- 공식 API의 새 버전 생성 요청은 `403 FORBIDDEN_ERROR`로 거부됐다. 기존 자동화 키로 읽기·빌드 업로드는 가능하지만 버전 생성은 허용되지 않는다. 권한을 확대하거나 로그인/승인 절차를 우회하지 않았다.
- 로그인 후 1.0.4 버전을 만들고 빌드 11을 선택한다. 준비한 변경사항·기존 스크린샷·기존 비공개 심사정보를 확인하고 `AFTER_APPROVAL`로 심사 제출한다. 실제 접수 상태와 출시 방식을 확인해야 완료다.

비밀값 없는 이번 출시 검증 기록·심사 문구는 `frontend/.verification/release-20261104/`에 보관한다. 운영/심사 배포 묶음은 로컬 보호 경로에 준비했으며 전체 실제 DB나 명단을 묶음에 넣지 않았다.
