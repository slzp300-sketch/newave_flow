# 찬양팀 디자인 정리 · 2026-11-05

배포 없이 실제 앱 컴포넌트를 수정했다. 운영 자료·서버·스토어는 변경하지 않았다.

## 반영 내용

- 찬양팀 페이지 제목에 담당 업무의 보라색과 음악 아이콘을 적용. 홈 메뉴 간격을 줄이고 `찬양팀 메뉴`로 정리.
- 명단의 학년/교사 펼침 버튼을 둥근 공통 디자인으로 통일. 인원 수 배지, 이름 영역, 선택 상태를 정리하고 각 버튼과 펼침 영역을 접근성 속성으로 연결.
- 월간 표·이전 콘티·활동 종료 명단을 같은 펼침 디자인으로 맞춤. 월간 표에 키보드 포커스와 내부 가로 스크롤 적용.
- 팀원 상세의 `교사 · 교사` 중복을 제거하고 담당 파트와 배정 일정을 구분.
- 팀원 수정의 파트 선택을 체크 카드로 정리. 선택한 항목은 초록색으로 구분.
- 로테이션 편집을 연습 일정 / 파트 배정으로 구분. 현재 배정 이름과 선택 인원을 표시.
- 편집창 제목·닫기·저장 버튼을 고정하고 내용만 스크롤. 검색과 교사/학생 필터도 명단 스크롤 중 유지.
- 기도회·학기 설정에 입력 항목 이름을 표시. 콘티 PDF도 같은 창 디자인과 고정 다운로드 버튼 사용.
- 편집 내용을 `PraiseEditor.jsx`로 분리. 저장 API, 권한, 공개/미공개 정책, 불가 일정 충돌 확인은 기존 로직 유지.

## 확인

- 프런트엔드 기존 검사 252개 통과.
- 최종 프런트엔드 빌드 성공: `.verification/praise-design-build`. 기존 큰 묶음 크기 안내만 남음.
- 가상 50명 명단에서 검색, 펼침/접기, 선택 유지 확인.
- 가상 팀원 담당 파트 변경 저장 및 로테이션 싱어 추가 저장 확인.
- 375×812, 320×740에서 문서/팝업 가로 넘침 없음.
- 긴 배정 명단을 2,303px 내려도 제목·닫기와 저장 버튼이 화면에 유지됨.
- 월간 표는 315px 영역 안에서 873px 표를 가로로 스크롤하며 페이지 폭은 375px 유지.
- 교사 역할에서 12/12 불가 날짜 제출 및 완료 상태 확인.
- 두 역할이 서로 다른 창에서 수정했을 때 기존 동시 변경 안내가 동작하고, 새로고침 후 기도회 진행자 저장 성공.
- 학기 만들기 입력창, 기도회 진행자 드롭다운, 콘티 미리보기 확인.
- 가상 콘티 PDF 다운로드 완료. 실제 자료는 사용하지 않음.
