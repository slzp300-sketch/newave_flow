# 일정 관리 사분할 정리 (2026-10-30)

- 배포·푸시·운영 자료 변경 없음.
- 보기 선택을 제거하고 항상 2열의 작은 카드로 표시. 날짜, 구분, 제목, 시간만 남기고 일정 색상은 상단 선으로 유지.
- 진행 중/예정/종료 분류, 검색, 기간 필터 유지.
- 카드 클릭 시 상세 창에서 설명, 날짜, 시간, 출석 대상과 접수 기간 확인. 수정·삭제는 상세 안으로 이동.
- 기존 달력 기간 선택, 하루종일, 일정 유형/색상, 출석 활성화/대상/접수 기간, 개별·일괄 등록 유지.
- 날짜 선택창을 상세 dialog 안에 표시하도록 선택적 portalTarget 추가. Esc는 날짜 선택창만 닫으며 이전 초점으로 복귀.
- 수정 취소 시 미저장 확인, 삭제 시 출석 기록 포함 안내, 저장 중 중복 요청 차단, 오류 시 입력 보존 및 오류 안내 초점 이동.

## 검증

- 프런트엔드 테스트 198개 통과.
- 최종 프로덕션 빌드 통과 (`.verification/calendar-admin-build`, 기존 번들 크기 경고만 존재).
- JSX 바인딩 검사 및 git diff --check 통과.
- 가상 Axios 자료로 실제 CalendarAdminPage 렌더링. 모든 미지정 요청 차단, 새로고침 시 가상 변경 복원.
- 브라우저: 상세 열기, 내용 수정·저장, 미저장 취소/계속 작성, 삭제 확인·삭제, 종료 필터, 기간 달력 선택, 개별 등록 및 출석 대상 반영 확인.
- 저장 오류를 주입하여 입력 보존 확인.
- 320px 폭 + 120% 글씨: 2열 유지, 페이지/상세 가로 넘침 없음. 상세 폭/스크롤 폭 모두 284px. 날짜 선택 후 Esc로 상세 편집 유지 확인.
- 일괄 등록 창 진입·두 제목 입력·등록 요청까지 확인. 기존 window.alert가 브라우저 도구를 막아 그 완료 후 목록 확인은 하지 못함. 해당 임시 탭을 닫아 복구했으며 일괄 등록 구현은 변경하지 않음.
