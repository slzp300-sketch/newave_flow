# Apple 로그인 연결 — 2026-10-16

## 구현과 계정 설정

사용자가 Apple 로그인 연동 완료와 노션 상세 기록을 요청했다. Apple 앱 권한·알림 주소·전용 키 발급, Railway 운영 서버 비밀값과 PC 암호화 보관, GitHub 기존 보호 환경 프로파일 갱신을 명시 승인했다.

- 앱 식별자에 Sign in with Apple 기본 App ID를 활성화하고 운영 HTTPS 알림 주소를 저장했다.
- 이 앱 전용 P-256 키를 발급해 Windows 사용자 DPAPI로 암호화했다. 별도의 32바이트 토큰 암호화 키를 생성·보관했다. 다운로드된 평문 개인 키는 암호화 왕복·서버 저장 확인 후 제거했다.
- 운영 서버의 Apple 설정 5개를 저장했다. 이 시점에는 로그인·알림 플래그를 끄고 배포하지 않았다. 가상 심사 서버에는 Apple 키를 넣지 않았다.
- 새 권한을 포함해 App Store 프로파일을 갱신했다. 팀·앱·형식·유효기간·인증서 일치·CMS 서명과 Apple 로그인 권한을 확인하고 `ios-testflight`의 프로파일 비밀값만 교체했다. 필수 검토자·main 제한·관리자 우회 금지는 유지했다. 최종 Apple 신뢰체인 및 서명은 macOS 빌드에서 확인한다.

## 기능 보완

- Apple 신규 가입은 서버가 확인한 이메일 또는 비공개 중계 주소를 사용한다. 이름은 확인·수정 가능하고 전화번호는 선택이며 별도 앱 비밀번호를 만들지 않는다.
- 클라이언트가 입력한 이메일·비밀번호는 Apple 가입에 사용하지 않는다. 기존 이메일과 일치해도 자동 병합하지 않으며 기존 계정 연결은 현재 비밀번호를 확인한다.
- Apple 전용 계정 삭제는 새 Apple 재인증과 일회성 증명이 필요하다. Apple 연결 철회가 성공해야 접수하며, 취소 시 요청을 보내지 않는다. 접수증 보관 후 로그아웃한다.
- 같은 Apple 계정의 새 동의로 철회된 연결을 복구할 수 있다. 삭제 접수 또는 Apple 계정 영구 삭제 상태는 차단한다.
- 개인정보 안내와 제출 초안을 갱신했다. App Store 개인정보 초안의 게시 및 연령 등급 결정은 별도 남은 작업이다.

## 운영 DB 검증과 적용

사용자는 운영 DB 전체의 암호화 백업·로컬 복원 검증과 운영 V011·V014 적용을 각각 명시 승인했다. 자동 승인 검토의 두 차단은 승인 범위 확인 후 해결했다.

- 09:43(KST) 암호화 백업 완료: 42개 테이블, 암호화 파일 224,063바이트. 원자료는 OneDrive 밖 보호 폴더에만 저장하고 기존 30일 보관 정책을 유지한다.
- 복원한 모든 테이블의 건수·해시가 백업과 일치했다. 각 SQL과 통합 트랜잭션의 강제 실패·원복, 기존 행 보존, 재실행 차단을 검증했다.
- 최신 서버 JAR를 로컬 복원 DB의 SELECT 전용 계정으로 실행해 `prod/validate` 및 Apple 알림 스키마를 확인했다. 임시 복원 DB·계정·평문 덤프는 제거했다.
- V011과 V014를 운영에 한 트랜잭션으로 적용했다. 모든 기존 행 해시 보존과 신규 알림 테이블이 비어 있음을 확인했다. 실제 회원 자료 변경·계정 삭제 검수는 하지 않았다.
- V014는 비밀번호 NULL 허용, Apple 인증 flow의 이메일 열 2개, DELETE/DELETE_READY 제약 확장만 추가한다. 새 서버를 배포하기 전에 적용했다.

## 검증

- 프런트 전체 101개 검사 및 배포 빌드 통과.
- 백엔드 전체 build·review JAR 생성 성공: 139개 실행 통과, 선택 PostgreSQL 검사 12개는 일반 실행에서 제외. 별도 PostgreSQL 13개 및 Node 개인정보 검사 7개 통과.
- iOS 배포 도구 60개 검사 통과. 제출 초안 검사와 스크린샷 묶음 생성 통과.
- 375px 가상 화면에서 비밀번호 없는 가입, 중계 이메일 줄바꿈, Apple 재인증 삭제 접수·취소, Apple 전용 프로필을 확인했다. 실제 API를 호출하지 않는 가상 자료만 사용했다.
- 프런트·백엔드 교차 검토 및 운영 DB 실행기 독립 검토에서 수정이 필요한 문제를 발견하지 못했다.

## 이 시점에 남은 단계

정확한 커밋의 운영 서버·웹 배포, 공개 개인정보 안내 확인, 서버 로그인·알림 활성화, Apple 권한을 포함한 새 TestFlight 빌드 업로드·처리·내부 그룹 연결과 실제 iPhone 인증 확인이 남았다. 자동 검사·포털 설정 완료를 실제 Apple 인증 또는 정식 출시 완료로 표시하지 않는다. 후속 완료 결과는 이 문서에 추가한다.

실제 개인 키·암호·토큰·DB 행·비공개 연락처는 이 문서와 노션에 기록하지 않는다.
