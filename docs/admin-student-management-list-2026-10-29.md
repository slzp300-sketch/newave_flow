# 학생 관리 목록 정리 — 2026-10-29

- 관리자 학생 관리의 명단 보기는 목록형만 남겼다. 큰 카드·작은 카드·표 보기와 전환 버튼을 제거했으며 기존 보기 저장값의 영향을 받지 않는다.
- 카드 윗줄에 이름·재적/제적 상태·세례 표시를, 아래에 학년·반과 학교를 정렬했다. 반·학교가 없을 때도 명시적으로 표시한다.
- 사진/이니셜을 작은 썸네일로 유지하고 정보 영역을 누르면 수정 창이 열린다. 아주 좁은 화면이나 큰 글씨 모드에서는 사진 대신 텍스트 공간을 확보한다. 전체 사진·입력 항목은 기존 수정 창에서 확인할 수 있다.
- 제적/복구 버튼을 정보 수정 영역과 나누고 글자 표기를 추가했다. 버튼은 최소 44px이며 요청 중 중복 실행을 막는다. 기존 제적 확인 문구와 API·새로고침 동작을 유지했다.
- 일반 항목은 375px에서 약 97~101px, 긴 이름·학교가 있는 가상 항목은 약 127px이다. 고정 높이·말줄임 없이 필요한 만큼 늘어난다.
- 학년별 명단·반 배정 현황의 기능 탭과 학년 필터·검색·제적 포함·학생 추가·학년 진급을 유지했다. 반 배정과 등록/수정·진급 창 코드는 원본 그대로 보존했음을 비교 확인했다. API·백엔드 변경은 없다.
