# 행사 출석 관리 사분할 정리

배포·운영 자료 변경 없이 프런트엔드와 가상 미리보기만 수정했다.

## 화면

- 큰 카드·목록·표 보기 전환과 과거 저장된 보기 설정을 제거. 행사, 학년, 개인 모두 작은 2열 카드로 표시.
- 행사 카드에는 날짜·대상·제목·접수 상태만 표시. 선택하면 해당 행사 현황으로 전환하며 행사 목록으로 돌아올 때 위치와 초점 복원.
- 학생/교사 전환, 학년별 카드, 이름·학년·반 검색을 제공. 중1/중2, 중3/고1, 고2/고3 순서 유지.
- 작은 통계 카드의 참석·부분참석·불참·미제출 숫자를 누르면 해당 인원만 표시. 전체 인원 버튼은 전체 명단을 표시.
- 이름을 누르면 상세 창에서 학년·반·불참 사유·부분참석 시작일과 메모 확인. Escape와 닫기, 초점 복원 지원.
- 학년별 제출 수는 참석·부분참석·불참 응답을 포함하며 출석 상태별 인원은 서로 분리.
- 현재 출석 대상이 변경되어도 과거 학생/교사 제출 기록이 있으면 해당 조회 탭 유지.
- 새로고침, 조회 실패·재시도, 빈 대상자 상태를 구분. 실패한 조회를 0명으로 표시하지 않음.

## 구현

- `EventAttendanceAdminPage.jsx`, CSS 정리.
- `eventAttendanceAdmin.js`: 인원 변환, 실제 개인 학년별 그룹, 상태·검색 필터, 기존 제출 기록 탭 판별.
- 반의 첫 번째 학생 학년으로 전체 반을 분류하던 방식을 개인 학년 기준으로 변경. 부분참석과 미제출을 분리하는 공통 집계 함수 사용.
- 읽기 요청에 사용자/환경별 캐시와 AbortSignal 사용. 서버 API와 출석 쓰기 권한은 변경 없음.

## 검증

- 프런트엔드 테스트 202개 통과(새 회귀 테스트 4개 포함).
- JSX 바인딩 검사와 git diff --check 통과.
- 로컬 빌드 성공. 기존 번들 크기 경고만 존재.
- 브라우저: 행사 선택, 학생/교사 전환, 학년 선택, 전체 48명 표시, 미제출+학년 검색(2명), 불참 사유, 부분참석 날짜·메모, 닫기/Escape 확인.
- 교사 전용 행사와 현재 교사 전용이지만 과거 학생 제출 기록이 있는 행사 모두 확인.
- 학생 조회 오류 시 학생 통계가 표시되지 않고 재시도 제공, 교사 탭은 정상 조회 확인. 대상자 없는 행사는 실제 0명 표시.
- 320px·큰 글씨(19.2px)에서 행사·개인 카드 2열 유지, 페이지 가로 넘침 없음. 개인 상세 clientWidth/scrollWidth 299px로 동일.
- 가상 어댑터는 지정된 GET 요청만 허용하며 실제 서버 요청·쓰기 차단.
