# 선택 푸시 알림 안내 — 출시 후 활성화용 초안

작성 기준: 2026-10-19. 코드 사전 준비용이며 현재 게시된 방침, 스토어 개인정보 신고, 운영 설정을 변경하지 않았다. 실제 키·프로젝트·처리 조건을 확정한 뒤 시행일을 정하고 기존 방침에 반영한다.

## 앱에 표시할 선택 안내

휴대폰 알림을 켜면 일정과 미제출 안내를 받을 수 있습니다. 알림 연결을 위해 기기 알림 토큰, 앱 설치 식별자, 기기 종류와 알림 수신 설정을 처리합니다. iPhone은 Apple, Android는 Google의 알림 서비스를 이용합니다. 잠금 화면에는 일반 안내만 표시하며 상세 내용은 로그인 후 앱에서 확인합니다. 언제든 내 정보에서 끌 수 있고, 알림을 거부해도 앱을 이용할 수 있습니다.

## 기존 개인정보처리방침에 추가할 내용

- 2절 처리 항목: 계정 ID와 연결한 설치 UUID, iOS/Android 구분, APNs/FCM 기기 토큰과 중복 방지용 해시, 제공된 앱 버전, 등록 갱신 시각, 알림 동의 여부를 선택 알림 전달에 사용한다. 알림 ID·종류·본문·읽음 상태와 전송 상태·시도 횟수·만료 시각은 앱 내 확인, 중복 방지, 실패 처리에 사용한다. 앱 자체 설치 UUID와 Google Firebase 설치 ID는 서로 다른 값이다.
- 4~5절 외부 처리: iOS에는 Apple APNs, Android에는 Google Firebase Cloud Messaging을 이용한다. 앱 서버가 보내는 내용은 대상 기기 토큰, 일반 제목·본문, 알림 ID 및 전송에 필요한 기술 정보다. 학생 이름, 출결 사유, 점수, 기도제목, 행사 상세 원문은 전송하지 않는다. 기기·알림 서비스 자체의 통신 정보는 제공자 정책에 따른다. 제공자별 계약 주체·국외 처리와 삭제 조건은 실제 프로젝트를 연결할 때 확인해 확정한다.
- 6절 우리 서버 보관: 기기 등록 해제·로그아웃 요청이 서버에 도달하면 해당 등록과 연결된 전송 내역을 제거한다. 다른 계정으로 등록을 바꾸면 이전 계정의 전송 내역을 제거한다. 제공자가 토큰 무효를 응답하면 해당 기기 등록과 전송 내역을 제거한다. 실제 계정 삭제 시 알림·동의·기기·전송 내역을 삭제한다. 오프라인 로그아웃은 서버 삭제 완료를 보장하지 않으며, 이후 계정 교체/등록 해제 또는 계정 삭제 시 정리한다. 알림을 끄면 모든 기기에서 그 계정의 새 푸시 발송을 차단하고, 조작한 기기의 등록을 해제한다. 다른 기기의 등록은 그 기기에서 다음 설정 확인 시 정리한다.
- 6절 제공자 보관: 우리 서버에서 토큰을 지우는 것과 제공자의 설치 식별자를 지우는 것은 별개다. 현재 Capacitor의 Android `unregister`는 자동 초기화를 끄고 FCM 등록 토큰 삭제를 요청한다. Firebase 설치 ID 삭제 호출은 별도이며 수행했다고 표시하지 않는다. Firebase 공식 안내는 설치 ID 삭제 API 호출 후 실제·백업 시스템의 제거에 최대 180일이 걸릴 수 있다고 설명한다. 이를 우리 앱 데이터의 삭제 기한으로 표시하지 않는다.
- 8절 기기 저장: 앱 설치 UUID만 웹 저장소에 두며 원문 푸시 토큰은 웹 저장소에 저장하지 않는다. 토큰은 네이티브 SDK와 서버에서 처리한다. 푸시를 눌렀을 때 현재 계정의 앱 내 알림 목록에서 소유권을 다시 확인하고 허용된 앱 화면으로 이동한다.

## 활성화 시 확인할 스토어 정보

- App Store의 식별자/기기 ID와 사용자 연결, 앱 기능 목적, 광고 추적 없음 항목을 실제 SDK 구성과 대조한다. Android Data safety도 같은 기준으로 대조한다.
- SDK의 Firebase 설치 식별자 처리를 포함해 수집/공유 신고와 제공자 삭제 절차를 확정한다. 가입·삭제 검수 자료에는 실제 토큰을 넣지 않는다.
- 실제 시행일, 외부 수령자·처리 지역·연락처·보관 조건을 확정하고 안내한 뒤 `PUSH_ENABLED`, 플랫폼별 전송, 네이티브 빌드 플래그를 활성화한다. 이번 브랜치에서는 모두 비활성이다.
