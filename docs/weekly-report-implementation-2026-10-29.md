# 주간보고서 구현 및 로컬 검증 — 2026-10-29

배포·푸시·PR·운영 DB 변경·교회 제출을 하지 않았다. 기존 화면 수정사항은 유지했다.

## 사용 흐름

1. 교사는 출석 체크에서 **본인의 청소년부 예배 출석**을 입력한다. TTS 본예배와 연결하지 않는다. 담당 반이 없는 임원·관리자도 본인 출석을 입력할 수 있다.
2. 담당 반별 배정 학생 출석과 선택 특이사항을 제출한다. 첫 방문·새가족은 새가족팀이 보고하며, 일반 교사는 예외적으로 반에 함께 온 첫 방문 참고 기록만 남긴다. 보고 구분·등반 여부는 교사가 변경하지 않는다. 여러 반을 맡았다면 반을 바꿔 각각 제출한다. 담임·부담임은 반/날짜 단위로 한 건을 공유한다.
3. 관리 메뉴 **출석 관리 · 주간보고서**(`/admin/weekly-report`)에서 원본 표를 본다. 공통 예배 순서·결재란 이름·헌금·계획을 입력하고 누락된 반/교사 출석만 보완한다. 기존 학생별 조회는 화면 상단 링크로 유지했다.
4. 누락이 없고 작성 중인 변경을 저장하면 HWPX/PDF를 받는다. 교회로 보내는 동작은 없다. 파일을 별도로 전달한다.

## 집계와 보존

- 보고일은 이번 주 또는 과거의 일요일, 예배 구분 없이 합산한다.
- 학생 한 명을 하나의 보고 구분에만 포함한다. 등반은 재적 안의 부분집합이며 전체 출석에 중복 가산하지 않는다. 지각 합산 여부는 관리자가 선택한다(기본 포함).
- 제출 전에는 미제출 반의 인원을 전체 합계에서 제외하고 미완성 경고를 표시한다. 성별/출석/새 인원 정보/공통 필드 미입력, 중복 학생, 수정 후 미제출은 최종 파일 생성을 막는다.
- 제출 시 명단·이름·반·성별·보고 구분·상태를 저장한다. 이후 명단 이동이나 수정이 이전 제출 내용을 조용히 바꾸지 않는다. 출석/추가 정보를 수정하면 다시 제출해야 한다.
- 기존 제출 기록에 저장본이 없는 경우 현재 명단/출석에서 읽고 ‘이전 제출 자료’로 표시한다. 과거 명단을 소급 복원한 것은 아니다. 기존 주차 출력 시 누락을 보완하고 내용을 확인해야 한다.
- 관리자 보완은 사유를 남기며 기존 결석 사유와 학생 메모를 보존한다. 사유는 교회 제출 문서에 섞지 않는다. 교사의 반 특이사항과 부서 공통 특이사항은 보고서에 합친다.
- 다른 교사의 제출/수정이 발생한 뒤 예전 집계로 출력하거나 예전 반 자료로 덮어쓰려 하면 충돌을 알려준다. 관리자의 공통 항목도 변경 버전을 확인한다.
- 출력 기록은 당시 자료를 보관하며, 동일 출력 기록의 HWPX/PDF는 같은 자료를 사용한다. 교사·학생이 이후 수정되어도 기존 출력 기록은 유지된다.

## 양식과 파일

- 제공된 `청소년부 주간보고서 (250622-25주차).hwpx`를 읽어 **943개 셀, 94행, 42열**의 원본 표 구조를 추출했다. 원본 파일은 변경하지 않았다.
- 재사용 템플릿은 기존 이름·연락처·숫자·특이사항 등 동적 영역을 제거한 파일이다. 원본과 셀 속성·병합·크기 943개를 대조했고, 원본 동적 한글 값이 남지 않는지 검사했다. 원본 실자료를 미리보기나 저장소에 복사하지 않았다.
- HWPX는 템플릿의 글꼴·문단·테두리·색·병합 정보를 보존하고 내용만 채운다. 11명보다 많은 새 방문자나 학년별 반 슬롯 초과 시 같은 행 형식을 확장한다.
- 화면과 PDF는 원본 표 좌표를 공통 렌더러로 출력한다. 10월 30일 한글 자체 출력본과 대조하면서 원본의 테두리 굵기·이중선·사선·강조·밑줄을 추가 반영했다. PDF는 검색 가능한 텍스트와 내장 Nanum Gothic을 사용한다. 따라서 **한글 전용 글꼴 및 한글 프로그램의 줄바꿈·쪽 나눔과 픽셀 단위로 같지는 않다.** HWPX에는 원본 글꼴 참조를 유지한다.
- PDF에 지원되지 않는 문자를 조용히 지우지 않고 수정 안내를 보여준다. 외부 문서 변환/폰트 서비스에 보고서를 전송하지 않는다.
- 문서 조회/다운로드는 관리자·목사·임원만 허용하며 no-store 응답이다. 교사는 담당 반과 본인 예배 출석만 수정할 수 있다.

## 적용 시 필요한 DB 변경(아직 적용하지 않음)

`backend/db/migrations/V015__weekly_church_reports.sql`에 제출 저장본, 주간 반 추가 정보, 교사 예배 출석, 관리자 공통 항목, 출력 기록 테이블을 정의했다. 현재는 로컬 검증만 완료했다.

계정 삭제 절차의 새 보관 영역도 목록에 추가했다. 본인 교사 예배 기록/숫자 연결은 제거하고, 출력본의 교사 인원은 익명으로 유지한다. 공통 보고서에 남은 이름·자유 문장·JSON 내용은 기존 행 단위 검토/교정 절차와 전체 텍스트 검사 대상이다. 운영 보존 정책을 우회해 자동으로 공통 보고서를 삭제하지 않는다.
