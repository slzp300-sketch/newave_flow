# 교사 출석·주간자료 간소화 — 2026-10-30

## 반영 내용
- 교사 본인의 청소년부 예배 출석을 출석/불참 한 번 선택으로 자동 저장한다.
- 학생 출석은 작은 목록 카드로 정리하고, 메모는 필요할 때만 펼친다. 불참 사유도 선택 입력이다.
- 담당 반 목록은 기존 배정 API를 사용한다. 다른 반의 주간자료 조회·저장은 서버에서도 차단한다.
- 등록 학생의 이름·성별·학교·주소·연락처는 교적부 자료를 사용한다. 교사가 보내는 중복 인적 정보는 서버에서 제거한다.
- 교사 성별은 개인정보에 한 번 등록한다. 미등록이어도 출석은 저장하며 관리자는 보고서 누락 안내에서 확인한다.
- 추가 입력은 접힌 선택 영역 하나로 정리했다. 이후 새가족팀 담당 범위를 확인하여 교사의 보고 구분·등반 변경은 제거했다. 첫 방문 참고 기록과 팀 확인 절차는 new-family-attendance-flow-2026-10-30.md를 따른다.
- 현재 등록 정보 변경은 다음 제출에 반영되며, 이미 제출한 보고서 자료는 재제출 전까지 보존한다.

## 검증
- 프런트엔드 191개 테스트 통과, 로컬 빌드 성공.
- 백엔드 전체 Gradle build 성공.
- 실제 로컬 PostgreSQL에서 V015/V016 마이그레이션, 롤백, 기존 자료 보존, 성별 이관, 중복 실행 방지, JPA 검증 통과.
- HTTP 테스트: 개인정보 성별 저장/조회, 교사 출석 자동 반영, 성별 미등록 저장 허용, 학생 등록 정보 우선 사용, 제출 자료 보존, 담당 외 반 접근 차단.
- 375px 미리보기: 가로 넘침 없음, 기본 학생 카드 약 69px, 출석 버튼 높이 44px.
- 실제 가상 DB 연결 화면에서 교사 출석 저장, 추가 정보 없이 반 제출, 이름만 입력한 방문자 제출 성공.
- 관리자 보고서에서 해당 방문자의 성별·상세 정보 누락 안내를 확인했다.

## 배포 상태
- 운영 배포·운영 DB 변경·push·PR은 하지 않았다.
- 향후 배포 시 V015 다음에 V016__teacher_profile_gender.sql을 적용해야 한다.
- 미리보기는 localhost:5195와 합성 자료 전용 localhost:8089를 사용한다.
