# 앱 복귀·화면 반응 최적화 — 2026-11-09

## 범위와 출시 조건

- 회계·총무 전용 페이지는 개발 범위에서 제외. 조직도 직책 자체를 삭제하라는 요청은 아니므로 유지한다.
- 최적화 → 사용자와 위젯 협의 → 위젯 개발/검증 → 출시 순서. 이번 작업은 로컬 수정이며 배포·스토어 업로드·운영 데이터 변경·커밋/푸시 없음.
- 위젯 내용은 사용자 답변에 따라 **가까운 일정 + 본인의 영성 체크/주간 체크사항**으로 정했다. 플랫폼 범위와 직접 체크/앱 이동 방식은 협의 중이며 위젯 코드·권한·공유 저장소는 만들지 않았다.

## 반영한 개선

1. `NativeRuntime`의 복귀 처리를 `appLifecycle`로 정리. Capacitor 활성 상태/pause/resume, WebView visibility/pageshow 중복 신호를 합치며 숨겨진 동안 Query의 화면 조회를 일시 정지한다. 초기 getState 응답이 늦어도 최신 상태를 덮어쓰지 않고 해제 후 늦게 등록된 listener도 제거한다.
2. 복귀 시 로그인 만료가 가까우면 기존 단일 refresh 작업을 공유해 갱신한다. 같은 계정의 토큰 갱신 때문에 화면을 ConnectingScreen으로 교체하거나 Query 자료를 통째로 비우지 않는다. 따라서 작성 중 화면/입력이 유지된다. 실제 계정·역할이 바뀌면 이전 역할의 캐시는 제거한다. 거절된 로그인은 기존처럼 종료한다.
3. 앱을 떠나기 전부터 15초 이상 대기한 GET/HEAD만 복귀 시 한 번 재연결한다. 원래 호출의 Promise·취소 신호·계정 범위를 유지한다. 짧은 복귀, 이미 끝난 요청, 사용자가 취소한 요청, 새 요청은 재시작하지 않는다. POST/PUT/PATCH/DELETE는 추적/자동 재전송하지 않는다.
4. Axios가 연결 실패 조회를 한 번 재시도한 후 Query가 다시 두 번 요청하지 않게 했다. 4xx/취소는 반복하지 않고 서버 5xx는 한 번만 재시도한다. API에서 401에 따른 정상 인증 갱신은 유지한다.
5. FitLabel의 ResizeObserver/MutationObserver, 폰트·창 크기 이벤트와 프레임 예약을 공통으로 묶었다. 라벨들을 먼저 측정하고 크기를 함께 변경한다. 큰 글씨 최솟값·자동 줄바꿈은 유지하며 잘라내지 않는다.
6. 아래로 당겨 새로고침할 때 React 상태를 화면 프레임당 한 번만 갱신한다. 당기는 동안 지연되는 transform transition을 제거하고 놓을 때만 복귀 전환을 적용한다. 작은 탭·입력/버튼·다중 터치·중첩 스크롤 보호는 유지한다.

## 검증

- `npm test`: **288개 통과**, 실패/제외 0. 새 회귀 14개: 네이티브 중복 이벤트/늦은 초기 응답/플러그인 실패/해제 경쟁, 실제 Axios adapter의 재연결·취소·계정 변경·쓰기 보존, Query 중복 재시도 방지, 라벨 공통 처리·큰 글씨·해제 등.
- 기존 터치·새로고침, Apple/로그인/푸시·권한 등 회귀도 포함한다.
- 웹 및 native mode Vite 빌드 성공, `npm run ios:verify` 성공.
- 백엔드 `gradlew.bat build` 성공. 백엔드 코드는 변경하지 않았으며 Gradle이 기존 성공 결과를 재사용했다.
- 100개 라벨 모형 검사: 관찰자 100쌍 대신 1쌍, 화면 예약 1개. 동일 글자 크기 결과를 유지하면서 읽기/쓰기 교차로 유발하는 layout 라운드를 라벨 수와 무관하게 4회로 묶었다. 이는 계산 순서 검증이며 실기기 FPS 수치가 아니다.
- 375px 가상 학생 페이지: 입력, 공통 선택 목록, 다른 화면을 다녀온 후 미저장 메모 유지, 취소 확인, 버튼 동작, 가로 넘침 없음, 브라우저 경고/오류 없음.
- 실제 RequireAuth를 사용하는 로컬 검증 화면: 가상 세션 갱신 중 버튼 클릭 성공, 갱신 후 메모 유지 및 화면 생성 1회. 큰 글씨 120%와 30개 긴 메뉴 라벨도 가로 잘림 없음. 인증 응답은 로컬 adapter이며 운영 계정/서버를 사용하지 않았다.
- 검증 파일은 `frontend/.verification/optimization-*.log`, 웹/앱 빌드 디렉터리, `optimization-session-app.*`에 있다. 학생 검증 서버 8097은 test 프로필·가상 자료·seed 비활성, 화면은 5207이다.
- `git diff --check` 통과. 초기 코드 약 565kB 경고는 남아 있으며, 단순 청크 분리만으로 속도가 개선됐다고 보고하지 않는다.
