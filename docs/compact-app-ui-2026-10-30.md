# 앱 설명·통계 카드 간소화

사용자가 확인한 기도모임 카드의 밀도를 앱 공통 기준으로 적용했다. 로컬 작업만 수행했으며 배포하지 않았다.

## 변경

- 출석, 주간보고서, 새가족, 교적부, 교사·학생·반 관리, 일정·행사, 기도모임·교사회의, TTS, 메뉴와 계정 연결 화면에서 제목·버튼과 중복되는 사용법 설명을 제거했다.
- 공통 `ui-metrics`는 제목 12px, 수치 16px, 구획 여백 8×10px을 기본으로 사용한다. 비율·점수 강조는 20px이다. 모두 rem 기반이며 좁은 큰 글씨 화면에서는 줄을 나눈다.
- `StatSummary`로 관리자 현황, 학생 현황, 행사 출석, 제출 완료 인원 카드의 마크업과 크기를 통일했다. 집계 값과 계산식은 변경하지 않았다.
- 보고서 상단의 중첩 카드 테두리·설명을 제거해 434px 화면에서 기도모임과 같은 117px 높이로 맞췄다. 일반 인원 요약은 62px, 새가족의 긴 분류명은 두 줄 카드로 123px이다.
- TTS 점수·분기 요약에서 반복 설명과 격려 문구용 빈 영역을 제거했다. 저장 중·실패 상태는 유지한다.
- 입력 조건, 재제출·미확인 상태, 권한 제한, 삭제·오류·보안 안내, 개인정보 문서와 사용자가 입력한 내용은 유지한다. 일반 버튼과 입력란의 터치 크기는 줄이지 않았다.

## 검증

- 프런트엔드 회귀 테스트 198개 통과.
- 전체 JSX 컴포넌트 참조 검사 통과. `git diff --check` 통과.
- 로컬 가상 자료로 교사 출석 입력·제출 완료, 주간보고서·공통 항목 펼침, 새가족, 교사회의 통계를 확인했다. 저장·제출·다운로드 동작은 실행하지 않았다.
- 새가족·교사회의의 320px 큰 글씨 화면, 실제 공통 컴포넌트의 관리자·행사·TTS 통계 320px 배치에서 가로 넘침 없음. 보고서 434px 일반·큰 글씨와 교사 출석 434px에서도 넘침 없음.
- 빌드 출력은 `frontend/.verification/compact-ui-build`에만 생성한다. 기존 혼합 import·청크 크기 경고 외 오류 없음. 추적 중인 `frontend/dist` 및 개인정보 HTML 변경 없음.

기존 수정사항을 보존했으며 운영 서버·데이터·권한 변경, 배포, PR 생성은 하지 않았다.
