# 심사 접근 및 실기기 검수 준비

## 심사 접근 초안

앱은 가입·관리자 승인이 필요한 교사 업무 앱이다. 심사자가 가입 승인 대기 없이 주요 기능을 확인할 수 있는 사전 승인 계정과 가상 반·학생·행사·TTS 기록을 준비한다. 실제 운영 명단이 보이는 일반 계정을 심사자에게 제공하지 않는다. 현재 서버에는 검수 계정의 자료를 격리하는 별도 테넌트가 없으므로, 계정만 하나 추가하는 방식은 안전한 심사 환경이 아니다.

심사 준비 순서:

1. 운영 사용자와 완전히 분리된 심사 환경 또는 검수 데이터 범위 제한을 구현한다.
2. 가상 자료만 보이는 교사·관리자 계정을 만들고 모든 조회·저장 범위를 확인한다.
3. 접수 중인 가상 행사와 이번 주·지난 주 TTS를 항상 검수할 수 있게 준비한다.
4. 최종 앱이 심사 경로에 접근하는 방법을 검증한다. 앱 기능을 심사 시 숨기거나 실제 기능과 다른 화면으로 속이지 않는다.
5. 계정·비밀번호는 저장소나 공개 문서에 넣지 않고 Play Console의 앱 액세스 항목에만 제공한다.

심사 계정: **미발급**. 접속 경로: **미확정**. 이 문서는 제출 완료를 의미하지 않는다.

## 화면별 확인 순서

| 순서 | 조작 | 기대 결과 |
| --- | --- | --- |
| 1 | 최초 설치·실행 | 파란 시작 화면 후 로그인, 잘림·빈 화면 없음 |
| 2 | 로그인·앱 재시작 | 승인 계정 로그인과 안전한 로그인 상태 복원 |
| 3 | 홈 기도·말씀 체크 | 체크·주간 점수·요일 표시 동시 반영, 전체 화면 재로딩 없음 |
| 4 | 빠르게 다른 항목 체크 | 최종 선택 보존, 저장 순서 일치 |
| 5 | 네트워크 단절 후 체크·재연결 | 실패/대기 안내, 성공하지 않은 기록을 저장 완료로 표시하지 않음 |
| 6 | 기록 수정·내 상세 통계 | 주간 수정 펼침, 개인 통계 바로 열림, 점수 일치 |
| 7 | 출석·공동 보고 | 가상 반 저장·제출, 동료 계정에도 완료 반영 |
| 8 | 행사 | 대상별 항목 표시, 접수 중 저장, 접수 전/후 비활성화 |
| 9 | 일정 | 종료 일정 회색, 계정별 확인 상태 기기 동기화 |
| 10 | 뒤로 가기·팝업·키보드 | 팝업 먼저 닫힘, 저장 중 이탈 방지, 입력칸/버튼 가림 없음 |
| 11 | 사진 선택·큰 글씨 | 선택한 사진만 처리, 취소 정상, 내용 잘림 없음 |
| 12 | 로그아웃·재시작 | 이전 사용자의 로그인/자료 노출 없음 |
| 13 | 지원·삭제 요청 | 비로그인 접근, 운영 주체와 이메일 일치, 외부 메일 앱 전달/직접 전송 안내 |
| 14 | 기존 앱 위 업데이트 설치 | 로그인/자료 보존, 새 홈 통계 표시 |

운영 계정으로는 조회만 한다. 저장·실패·삭제 테스트는 확인된 가상 자료 환경에서만 수행한다. 자동 테스트와 브라우저 검수는 실기기 통과를 대신하지 않는다.

## 연결 안내

USB 연결 후 개발자 옵션의 USB 디버깅을 켜고 휴대폰에서 이 PC의 연결을 허용한다. 검수 후 원하면 USB 디버깅을 끄고 허용한 PC를 해제할 수 있다. 비밀번호·인증번호는 채팅에 보내지 않고 휴대폰에 직접 입력한다.
