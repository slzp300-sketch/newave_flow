# Android 1.0.2(7) · TTS 화면 간소화

## 요청·범위

2026-10-19 사용자가 갤럭시 비공개 테스트에 NF-012 TTS 통계 간소화까지 반영하도록 요청했다. Android 전용 새 빌드이며 iOS 제출·main·운영 서버/웹·DB 변경은 포함하지 않는다. 앞선 서버 변경은 이미 배포되어 추가 마이그레이션이 필요하지 않다.

- 제품 변경 `fd95f94`: 내 체크 / 분기 순위 두 탭, 주간 상세·내 추이·주차별 요약·소속 필터·요약 지표 제거. 연도·분기·이름 검색·보기 형식·순위·이름·점수 유지.
- 버전 커밋 `eb07483`: app.newaveflow.mobile, versionName 1.0.2, versionCode 7. iOS 버전과 entitlement 변경 없음.
- Play 확인: 기존 1.0.1(6)은 10월 19일 14:25 KST에 Alpha 100% 출시되었고 ‘선택한 테스터에게 제공됩니다’ 표시. 정식 프로덕션 공개가 아니다.
- 이번 배포도 동일 Alpha·대한민국·기존 참여 링크를 사용한다. 새 테스터 12명 이메일은 아직 수집 중이다. 인원 모집과 등록·참여 완료를 구분한다.
- 푸시는 서버·네이티브 모두 기존 비활성 설정 유지.

## 검증·제출 기록

- 코드 검사: 프론트 135개 자동 검사·웹 빌드 성공. 375px 가상 화면에서 홈→내 체크→분기 순위, 보기 4종, 이름 검색 순위 보존, 미래 분기 안내, 넘침·콘솔 오류 없음 확인.
- Android native sync 및 bundleRelease·lintRelease 성공. 릴리스 lint 오류 0, 경고 32개(기존 경고 포함). 기존 자체 서명 업로드 인증서 일치 및 JAR 서명 검증 통과.
- AAB: 10,168,993바이트. SHA-256 `f67aa00ae2120c025be63d8ec0c280c5c74f81557b30589a14ba51c6b546e56a`. 번들 안 eb07483 빌드 식별자·운영 API 주소·비디버그 manifest·versionCode 7 확인. 개인 키 헤더·금지 파일명·서비스워커 미포함 확인. native push false로 빌드.
- 로컬 결과물: 원래 작업 폴더 `.verification/android-1.0.2-candidate/newaveflow-1.0.2-7-eb07483.aab`. Git에는 올리지 않는다.
- 기존 Play App Signing 업로드 키를 재사용한다. 키·비밀번호·심사 계정은 Git/노션에 기록하지 않는다.
- 1.0.2 실제 갤럭시 설치·업데이트 검수는 Google 제공 이후 별도다.
- Google 업로드에서 7(1.0.2), 최소 API 24·타깃 36, ABI 4개 확인. 지원 휴대전화 12,379·태블릿 6,803으로 이전 버전 대비 제외 0. 경고 2건은 매핑 파일/네이티브 디버그 심볼 부재이며 차단 오류는 없었다. 업데이트 예상 크기는 480KB.
- 14:48 KST Alpha 릴리스 3의 변경 1건 검토 전송 확정. 게시 개요에서 ‘검토 중인 변경사항’ 확인. 빠른 자동 검사 중이며 성공 후 Google 검토 전송되는 상태로, 새 버전 승인/설치 가능 완료는 아직 확인하지 않았다. 관리형 게시가 꺼져 있어 승인 후 동일 Alpha 테스터 전체에 제공되는 설정이다.
- 이번 작업에서 서버·DB·웹/main·iOS 제출을 변경하지 않았다. NF-012의 이전 ‘미배포 보관’ 기록은 이 Android 제출 기록으로 갱신되며, iOS/웹 반영은 여전히 별도다.
