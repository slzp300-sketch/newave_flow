# 뉴웨이브 플로우 개인정보 처리방침 — 공개 전 검토 초안

작성 기준: 2026-10-12. 이 파일은 확정·공개된 방침이 아니다. 아래 미확정 항목을 운영자가 확인하고 실제 처리 절차와 일치시킨 뒤 웹과 앱에 게시한다. 법률 검토를 대체하지 않는다.

## 운영 주체와 연락처

제자광성교회 뉴웨이브 청소년부는 뉴웨이브 플로우(Newave Flow)를 운영한다. 개인정보 열람·정정·삭제·처리 관련 문의는 `slzp300@gmail.com`으로 접수한다. 스토어 개발자는 개인 명의이며 실제 개인정보 운영 주체는 위 단체로 확인받았다. 책임자 직책·성명 및 교회 내부 위임 범위는 공개 전 확정한다.

## 처리 목적과 항목

| 목적 | 코드에서 확인한 항목 | 확인 사항 |
| --- | --- | --- |
| 계정 가입·승인·인증 | 이름, 이메일, 암호화된 비밀번호, 계정 ID, 권한, 승인 상태, 생성·수정 시각 | 계정 이용에 필요한 항목 |
| 교사 프로필·연락 | 전화번호, 생년월일, 프로필 사진, 직분, 담당 학년·반 | 가입 전화번호는 선택 입력. 각 프로필 항목 필수 여부 최종 확인 |
| 학생·반 관리 | 이름, 생년월일, 성별, 학교, 학년·반, 연락처, 주소, 세례 여부, 사진, 보호자 이름·연락처 | 교사가 입력하는 제3자 정보. 수집 근거와 안내·동의 절차 확인 |
| 영성·출석·행사 | 말씀·기도 실천, 예배·모임 참석, 출석·결석 사유, 행사 참석, 개인 점수·통계와 과거 스냅샷 | 종교 관련 민감정보와 자유 텍스트 포함 가능 |
| 공동 업무 | 반 보고서, 회의록, 기도모임 응답, 전도·새친구 기록, 일정 확인 상태 | 자유 텍스트에 불필요한 민감정보를 쓰지 않도록 안내 필요 |
| 문의·권리 행사 | 이메일 주소, 요청 내용, 본인 확인 및 처리 이력 | 비밀번호·신분증·주민등록번호를 요청하지 않음 |

회원·프로필 입력과 교사의 업무 기록으로 정보를 받는다. 시스템 주소록, 위치, 통화·SMS를 읽는 기능은 현재 앱 코드에 없다. 사진은 이용자가 선택한 파일을 업로드한다. 서버·호스팅의 접속 로그 항목과 보관 기간은 설정 확인이 필요하다.

## 이용 범위와 외부 처리

계정 권한과 담당 업무에 따라 허용된 교사·관리자가 자료를 조회·처리한다. 운영 서버 및 데이터베이스는 Railway, 웹 배포는 Vercel을 사용하며 운영 PC에 암호화 백업을 보관한다. 문의는 위 Gmail 주소로 접수한다.

공개 전 각 서비스의 계약 주체, 위탁 업무·항목·보관 기간, 실제 저장 국가, 국외 이전 여부와 적용 절차를 확정한다. 교회 밖 제3자 제공 여부도 운영자가 확인한다. 호스팅을 사용한다는 이유만으로 법적 제3자 제공 또는 Google의 데이터 공유 항목을 일괄 확정하지 않는다.

## 보관과 파기 — 확정 필요

사용자 결정은 본인 확인 후 계정·연락처·프로필·개인 TTS 기록 삭제, 반 공동 보고서는 개인을 식별할 수 없게 처리한 뒤 보존하는 방식이다. 학생 기록과 다른 구성원의 정보는 요청 범위 및 처리 근거를 별도로 확인한다.

현재 PC 백업에는 자동 만료가 없다. 따라서 ‘요청 후 30일 이내 모든 백업 삭제’ 같은 기한을 약속할 수 없다. 공개 전에 다음을 확정하고 구현한다.

1. 계정·개인 기록의 보관 종료 기준과 삭제 처리 기한.
2. 공동 기록 익명화 범위와 보관 목적·기간.
3. 백업 보관 기한·만료 자동화·삭제 요청 이후 복원 시 재적용 절차.
4. 학생·보호자 자료의 보관 종료 기준.
5. 법령에 따라 예외 보존할 자료가 있다면 근거·항목·기간.

전자 자료는 복원할 수 없도록 제거하고 공동 자료는 개인 식별을 제거한다는 운영안을 사용한다. 실제 삭제 실행 절차는 `../account-deletion-runbook.md`에 따라 별도 복원본으로 검증한 뒤 확정한다. 현재 앱의 삭제 기능은 이메일 요청 안내이며 자동 삭제 실행은 아니다.

## 권리 행사

앱의 고객지원·계정 삭제 요청 안내에서 이메일을 작성하거나 `slzp300@gmail.com`으로 직접 연락할 수 있다. 이메일 작성 버튼만 누르면 접수된 것은 아니며 직접 전송해야 한다. 로그인할 수 없는 경우에도 요청 가능하다. 담당자는 필요한 최소 정보로 본인을 확인하고 열람·정정·삭제 등의 처리 결과를 안내한다. 적용되는 법령과 타인의 권리에 따른 제한이 있다면 사유를 안내한다.

## 보호 조치

앱과 API는 HTTPS를 사용하고 비밀번호는 서버에서 해시 처리한다. 기능별 접근 권한을 적용하며 Android 로그인 상태는 Android Keystore를 이용해 암호화한다. 앱 데이터의 Android 자동 백업·기기 복사도 제외하도록 설정했다. 운영 PC 백업의 암호화·복원 절차와 담당자 접근 관리는 유지한다. 이러한 구현이 모든 사고를 방지한다는 보장은 아니다.

## 미성년자와 민감정보

앱 이용자는 교사이지만 학생·보호자의 정보와 종교 활동을 처리한다. 실제 정보주체의 나이, 만 14세 미만 포함 여부, 법정대리인 절차 및 종교 관련 정보 처리 근거를 교회 운영자가 확인해야 한다. Google Play의 앱 대상 연령과 저장 데이터의 정보주체 연령은 다른 항목이다.

## 변경 안내

시행일, 변경 전후 안내 방식과 공지 기간을 확정한 뒤 이 절을 완성한다. 초안 날짜를 시행일로 사용하지 않는다.
