## 그림 및 캡처 기준

Google 공식 요구 규격: 아이콘 512×512 32-bit PNG(1MB 이하), 그래픽 1024×500 JPEG 또는 알파 없는 24-bit PNG. 스크린샷은 최소 2장, 각 변 320~3840px이며 긴 변은 짧은 변의 2배 이하. 현재 초안은 400×800 CSS 뷰포트에서 캡처해 실제 파일 385×770으로 저장됐다. 파일 크기·색상 채널·비율은 `asset-manifest.json`으로 검증했다. 추천 영역용 1080×1920 실기기 캡처는 별도다. 캡처를 단순 확대해 실기기 원본이라고 표시하지 않는다.

각 이미지 대체 텍스트:

- 홈: 오늘의 말씀과 기도 체크 아래 주간 점수, 달성률과 월요일부터 토요일까지 실천 기록.
- TTS: 개인 분기 합계와 주별 점수를 확인하는 영성체크 상세 통계.
- 일정: 이번 달 일정과 행사 내용을 확인하는 달력.
- 출석: 담당 반의 가상 학생 출석과 반 공동 출결보고.
- 그래픽: 파란 파도 배경 위 뉴웨이브 플로우와 말씀, 기도, 일정을 소개하는 문구.

## 출시까지 남은 조건

1. Play Console 신원·전화번호·기기 인증 완료(2026-10-13 사용자 확인). 카카오 운영 반영 후 새 앱 생성과 등록 준비를 진행한다.
2. 개인정보 처리방침·실제 삭제 절차·백업 보관 기한과 민감정보/미성년자 처리 확정.
3. 운영 native 출처 허용과 새 화면 배포, 기기 로그인·주간 통계 표시·재실행 로그인 유지 확인 완료(2026-10-12, 실기기 결과는 사용자 확인).
4. Android 실기기 전체 시나리오와 가상 심사 환경 검증.
5. 업로드 서명 키·복구본·패키지 이름 확정, 앱 아이콘 lint/의존성 경고 검토.
6. 내부 테스트 업로드, 계정에 적용되는 비공개 테스트 및 출시 신청.
