## 사용자 확인 대기

1. 가상 교사·관리자 로그인 암호 자동 입력: 원본은 OneDrive 밖 접근 제한 ReviewOnline 폴더다. Codex 샌드박스 계정은 이 파일을 읽을 수 없다. 등록용 임시 복사본은 가상 계정 4개 필드만 포함하며 운영 DB/JWT/서명 키는 포함하지 않는다. 자동 승인 검토가 Codex 실행 그룹에 임시 읽기를 주는 접근 변경을 명시적 승인 부족으로 거절했다. 우회하지 않고 사용자에게 해당 임시 권한을 요청했다. 승인 후 읽기·Google Play 입력·임시 파일 삭제 순서로 진행한다. 암호를 채팅·노션·Git·스크린샷에 남기지 않는다.
2. IARC 법적 사용 약관: 사용 시점 확인 규칙에 따라 아직 수락하지 않았다. 이메일·다른 모든 앱 유형을 입력해 수락 직전 화면을 준비했다. 정확한 응답·관련 변경 시 재평가 의무를 포함한 약관 동의/설문 제출 승인을 요청했다.

가상 관리자 이름·ID·영어 설명만 준비했다. 비밀번호 입력·추가·최상위 저장은 아직 하지 않았다. 계정 입력 이후 전체 기능을 확인할 수 있도록 교사·관리자 각각의 안내를 제공한다.

승인 대기 중 만든 임시 암호 복사본 2개는 정확한 경로·단일 파일을 확인해 삭제했다. 원본 ReviewOnline과 키·암호 파일은 그대로다. 승인 후에는 필요한 임시본 1개만 다시 준비해 승인된 Codex 실행 그룹 읽기를 적용하고 등록 즉시 삭제한다. 이번에는 그룹 읽기 권한이 실제 적용되지 않았다.

## 승인 후 진행 — 2026-10-14

위의 승인 대기는 이후 사용자의 “승인해줄게 다시 진행하자” 답변으로 해소됐다. 이전 상태는 이력을 위해 남긴다.

- 승인된 Codex 실행 그룹의 읽기는 가상 계정 4개 필드만 포함한 등록용 임시본에 한정했다. 저장 직후 임시 파일과 폴더를 삭제했다. 원본 ReviewOnline·서명 키는 보존했으며 채팅·노션·Git에 암호를 기록하지 않았다.
- 교사 설명란에 관리자 암호를 중복 입력하는 시도는 자동 승인 검토가 거절해 수행하지 않았다. 별도 관리자 항목을 참조하는 안내로 바꿨다. 추가 공유로 해석된 모호한 스위치 클릭도 거절됐으며 명시적으로 끈 상태를 확인한 뒤 저장했다.
