# 개인정보 문서·새 Android 앱·Play 설정 재개 기록

## 2026-10-14 후속 진행

- 운영자가 학생 범위 중1~고3, 외부 판매 없음, 새 안내·필요한 개별 동의를 실제 확인 날짜부터 기록하도록 승인했다. 만 14세 미만이 포함될 수 있어 만 나이·법정대리인 확인 절차를 준비했다.
- `privacyPolicy.js`를 `publicationReady=true`, 시행일 2026-10-14 확정본으로 바꿨다. 민감정보·국외 처리·거부 경로와 제공자별 항목/목적/시기·방법/기간을 안내한다. Vercel·Gmail의 글로벌 처리와 제공자 자체 기록의 불확정 삭제 일수를 숨기지 않는다.
- `docs/privacy-consent-operations-2026-10-14.md`에 개별 동의·법정대리인·실제 확인일 기록 양식을 마련했다. 실제 대상자 동의 수집이나 자동 수집 기능, 공급자 계약 검토가 완료됐다는 뜻은 아니다. 실제 자료 변경은 하지 않았다.
- 확정본 프런트 73개 검사·웹 빌드 성공. `.verification/privacy-final-web`의 공개 HTML 스크립트 0개·9개 절 확인. 모바일 앱 문서 검토 표시 없음·가로 넘침 없음·콘솔 오류 0건.
- 원격 main은 아직 0419c26이며 병행 `codex/android-release-verification` 브랜치는 원격에 없다. 의존성 파일 버전은 건드리지 않았다. 병행 작업 결과가 게시되면 최종 앱 기준과 다시 대조한다.
- 기본 빌드가 과거 추적된 dist를 변경해 이를 커밋에서 제외했다. 자동 승인 검토가 dist 복구를 기존 작업 손실 가능성으로 거절해 복구를 재시도하지 않고 보존했다. 별도 검증 폴더 빌드는 통과했다.

아래는 10/13 준비 당시 이력이다. 배포·서명·Play 실제 저장 결과는 다음 기록에 추가하며 준비 상태를 완료로 과장하지 않는다.

2026-10-13, Windows 개발 PC `upup0`. 최신 main `0419c26`을 기존 로컬 작업을 보존하며 fast-forward로 받았다. 아래 변경은 아직 커밋·운영 배포하지 않았다.

## 구현 및 검수 완료

- 개인정보 내용의 공통 원본: `frontend/src/content/privacyPolicy.js`. 현재 `publicationReady: false`, 시행일 미확정이다.
- 앱의 비로그인 `/privacy` 화면, 로그인·회원가입·내 정보·고객지원·계정 삭제 안내의 문서 링크를 추가했다. 목차 이동이 앱 뒤로가기 이력에 새 항목을 만들지 않도록 했다.
- 앱과 같은 원본으로 JavaScript 없이 읽는 `public/privacy/index.html`을 생성한다. Vercel `/privacy`는 이 HTML에 연결한다. 공개 URL은 확정·배포 후 `https://newave-flow.vercel.app/privacy`다.
- `prebuild`·`preandroid:sync`에서 문서를 생성한다. 미확정 상태에서는 정상 릴리스 빌드를 거부한다. `ALLOW_PRIVACY_DRAFT=1`은 로컬 검토용이며 운영 배포·Play 업로드에 사용하지 않는다.
- 프런트 73개 검사 통과, 검토용 웹 빌드 통과. 뒤로가기 변경 후 관련 6개 검사 통과. 375px에서 앱·공개 HTML의 가로 넘침 없음, 공개 HTML의 스크립트 0개 및 9개 문서 절 확인. 로그인/회원가입 → 문서 → 원래 화면 복귀 확인.
- Android native sync, `bundleRelease`, `lintRelease` 성공. 검토용 미서명 AAB에는 앱 문서와 공개 HTML이 포함되며 명단·개인 키·암호·심사 접근 파일이 없다. 실기기 설치·검수 완료로 보고하지 않는다.
- Play Console의 최대 versionCode 2를 직접 확인해 다음 후보를 3으로 설정했다. 기존 버전 1은 내부 테스트 제공 중, 버전 2는 초안이다. 새 버전 3은 아직 서명·업로드하지 않았다.
- 기존 업로드 키 `newaveflowupload`의 공개 인증서 SHA-256이 인계 지문과 일치한다. 개인 키·암호는 기존 접근 제한 폴더에 유지하고 외부로 전송하지 않았다.
- 기존 온라인 심사 서버 `newave-review`의 실제 교사·관리자 암호를 비공개로 확인해 양쪽 로그인 성공과 역할을 검사했다. 이 PC의 예전 미배포 준비 암호를 사용하지 않았다. 필요한 접근 자료는 OneDrive 밖 사용자/SYSTEM 접근 제한 `ReviewOnline` 폴더에 보관했다. 공개 문서에는 암호·토큰을 적지 않는다.

## 개인정보 확정에 필요한 사용자 답변

1. 현재 자료에 만 14세 미만 학생이 포함되는지.
2. 교회 업무·호스팅·카카오 인증·문의 외에 외부 판매 또는 광고·마케팅 목적 제공이 있는지.
3. 기존 자료를 동의 완료로 간주하지 않고, 새 안내와 필요한 민감정보·국외 이전 별도 동의를 실제 확인 날짜부터 기록하는 운영 절차로 진행할지, 다른 확정된 처리 근거가 있는지.

이 답변은 아직 받지 않았다. 방침을 읽는 링크는 동의 수집 기능이 아니다. 실제 확인하지 않은 별도 동의·법정대리인 절차·국외 이전 근거를 완료된 사실로 만들지 않는다. 기존 실제 자료를 일괄 삭제·이관하지 않았다.

## 공개 전 추가 대조

- 원본 문서의 검토 표시와 미확정 문구는 사실·절차 확인 후에만 확정 내용으로 교체하고 시행일을 정한다. 기존 보관 기준은 유지한다.
- Railway 운영 DB의 미국 보관, Vercel 웹 전달, Google 문의 접수를 구분해 수령자·연락처·항목·국가·시기/방법·보관 기준·거부 경로를 정리한다. 제공자 자체 로그의 조회 기간을 실제 완전 삭제 기간으로 단정하지 않는다.
- Railway 공개 DPA 부속서의 민감정보 범위가 `None`으로 기재돼 있으므로, 현재 종교·건강정보의 계약상 처리 범위를 확인한 것으로 간주하지 않는다. 공개 약관에서 일괄 금지 조항을 확인한 결과는 아니다.
- Google 데이터 보안에는 실제 건강정보와 종교 관련 정보를 포함한다. 의료 기능 없음과 건강정보 수집 없음은 다른 선언이다.

근거: [개인정보위 작성지침](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS217&mCode=G010030000&nttId=12018), [국외 이전 조문](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334957), [Railway DPA](https://railway.com/legal/dpa), [Railway 로그](https://docs.railway.com/observability/logs), [Vercel 개인정보 안내](https://vercel.com/legal/privacy-notice), [Google 데이터 보안](https://support.google.com/googleplay/android-developer/answer/10787469?hl=ko).

## 답변 후 요청한 순서대로 진행

1. 처리방침 내용·운영 기준 확정 → 프런트 검사·빌드 → main 반영 및 공개 `/privacy`·앱 링크 확인.
2. 확정본으로 native 재빌드 → 기존 키로 서명 → 인증서·버전·비밀값 미포함 검사 → Play 새 AAB 업로드. 현재 로컬 검토 AAB를 최종본으로 업로드하지 않는다.
3. 실제 온라인 가상 심사 계정 앱 액세스 등록 → 18세 이상 대상·콘텐츠 등급·건강정보 포함 데이터 보안·개인정보 URL 완료. IARC 약관은 실제 수락 단계에서 필요한 사용자 확인을 받는다.

테스터 명단 수집 및 12명/14일 비공개 테스트 시작은 아직 완료되지 않았다. 기존 `README.md`, `frontend/vite.config.js`, `docs/local-development.md`, `tools/dev/` 변경을 보존했다.
