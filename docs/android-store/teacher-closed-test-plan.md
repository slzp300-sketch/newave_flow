# 교사 12명 비공개 테스트 준비

2026-10-13. 실제 뉴웨이브 교사 약 12명 참여 예정이라는 사용자 확인을 반영했다. 이 문서는 초대 발송·비공개 트랙 게시·14일 시작 완료를 뜻하지 않는다.

사용자는 Google Play 계정 이메일을 다음 주 모은 뒤 테스터 등록을 진행하기로 했다. 기기는 갤럭시로 한정하지 않으며 앱을 설치·실행할 수 있는 Google Play 지원 Android 기기가 필요하다. iPhone만 보유한 사람을 Android 테스트 참여 인원으로 계산하지 않는다.

## 사용할 테스트

- 내부 테스트: 최대 100명에게 빠르게 배포하는 검수 단계. 이전 작업에서 1.0.0(1)이 게시됐고 1.0.0(2)은 초안으로 업로드됐다. 이번 PC의 Console 접속과 대시보드 내부 테스트 상태를 확인했다. 버전 2 게시 결과는 완료 후 별도로 기록한다.
- 비공개 테스트: 이 개인 계정의 정식 출시 준비에 사용할 단계. 최소 12명이 참여를 선택하고 14일 연속 유지해야 한다. 가능하면 예비 1~2명을 더 확보한다. 기간 충족만으로 자동 승인되는 것은 아니며 실제 이용·피드백과 준비 상태를 설명해야 한다.
- 내부 테스트에 이미 참여한 사람은 먼저 내부 테스트에서 나간 뒤 비공개 테스트에 참여해야 한다. 내부 테스트 기간을 비공개 14일에 합산하지 않는다.

## 게시 전 순서

1. **완료:** TTS 통계 개선을 회귀 검사와 합성 100명 조건으로 검증하고 운영 서버에 반영했다(df99847).
2. **완료:** 사용자 추가 사용료 동의 후 가상 심사 서비스 1개·전용 볼륨 1개를 배포했다. 실제 명단이나 운영 DB 접속값을 전달하지 않았다. 온라인 로그인·저장·재시작·운영 토큰 거부를 검증하고 운영 서버에 심사 API 주소를 설정했다.
3. Play 앱 액세스에 가상 교사·관리자 계정을 등록한다. 암호는 비공개 입력란에서만 전달하고 노션, Git, 스토어 설명에는 적지 않는다.
4. 비공개 테스트에 필요한 스토어 등록정보·개인정보 처리방침 공개 URL·데이터 보안·콘텐츠 등급·타겟층·국가 설정을 실제 Console 체크리스트와 대조해 완료한다. 이전 초안을 사실 확인 없이 제출하지 않는다.
5. 교사들이 Play 스토어에서 사용하는 Google 계정 이메일 목록 또는 Google 그룹을 준비하고 비공개 트랙에 등록한다. 이 문서와 공개 노션 로그에는 이메일 목록을 적지 않는다.
6. 기존에 서명·업로드된 버전 코드 2를 사용할 수 있는지 Console에서 확인하고 테스트 트랙에 배포한다. TTS 서버 코드만 바꾸는 이번 개선은 새 Android 서명키나 AAB를 요구하지 않는다. 이후 새 앱 버전을 만들 때에는 다른 PC의 기존 Play 업로드 키를 안전하게 이전해야 한다.
7. 비공개 테스트 참여 링크로 12명 이상 참여가 확인된 시각부터 기간을 기록한다. 링크 배포 자체를 참여 완료로 계산하지 않는다.

2026-10-13 Console 확인: 앱 설정은 11개 중 0개 완료로 표시되고 비공개 테스트는 설정 완료 후 시작하도록 안내한다. 현재 비공개 참여 0명. 남은 설정은 개인정보처리방침, 로그인 세부정보, 광고, 콘텐츠 등급, 타겟층, 데이터 보안, 정부 앱, 금융 기능, 건강, 앱 카테고리/연락처, 스토어 등록정보다. 이 상태에서는 내부 테스트는 가능하지만 비공개 14일은 아직 시작되지 않는다.

## 교사용 안내 초안

테스트 참여 링크는 비공개 버전이 게시된 후 확정한다. 이전 내부 테스트 링크와 구별한다.

- 등록한 Google 계정으로 참여 링크를 열고 참여를 선택한 뒤 Play 스토어에서 설치한다. 다른 Google 계정이면 설치 권한이 없을 수 있다.
- 본인의 기존 뉴웨이브 계정으로 로그인한다. 실제 교사들은 기존 운영 자료를 사용하므로 출석·행사·TTS는 실제 상황에 맞게 기록한다. 시험 목적으로 가짜 출석이나 완료 체크를 넣지 않는다.
- 첫날: 로그인, 홈 주간 기록, 일정, 출석, 행사, TTS 통계, 뒤로가기, 앱 재실행 후 로그인 유지 확인.
- 기간 중: 평소 업무에 맞춰 기도·말씀 체크와 주간 기록·통계 반영, 행사 접수 상태, 실제 반 출결보고, 앱 업데이트와 재실행을 확인한다. 사용하는 Android 기종·버전도 기록한다.
- 오류 제보: 발생 시각, 화면 이름, 동작 순서, 기대 결과와 실제 결과를 담당자에게 전달한다. 비밀번호·인증번호는 보내지 않고 학생 이름·연락처가 보이는 캡처는 가린다.
- 최소 14일 연속 참여를 유지하고 테스트 중 발견한 문제는 수정 버전으로 다시 확인한다.
