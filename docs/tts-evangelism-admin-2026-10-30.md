## 전도관리
- 조·일정 보기 선택기 제거, 작은 2열 카드와 상세 대화상자로 통일.
- 이름·학년 검색, 현재 조 필터, 표시된 교사 다중 선택, 일괄 이동·배정 해제.
- 후속 수정: 현재 조·이동할 조·시작 조·일정별 담당 조·일정 간격의 기본 선택기를 공통 CompactSelect 펼침 목록으로 교체. 앱의 파랑/초록 상태색, 선택 체크, 목록 내부 스크롤, 화면 공간에 따른 위/아래 펼침 적용. 방향키·Home/End·Enter·Escape·Tab 지원.
- 미배정 교사의 자동 배분: 현재 인원이 적은 조부터 채움. 확정 전에 조별 인원 표시, 기존 조원 유지.
- 조 추가·이름 수정·삭제 유지. 조 삭제는 기존처럼 비활성화하며 기존 일정 보존.
- 일정 일괄 등록: 날짜별 조 편집, 행 추가·제외, 시작 날짜/횟수/매주·2주·4주 간격/시작 조를 기준으로 순환 일정 생성. 최대 52건.
- 동일 날짜·조의 중복 차단. 취소된 일정은 같은 날짜·조로 다시 등록 가능.
- 일정 상세에서 수정·취소·삭제. 조원이 없는 조도 책임 조 식별자를 응답에 포함하여 이름 표시.
- 새 일괄 API는 관리자·목사·임원만 접근. 전체 요청을 검증하고 트랜잭션으로 함께 저장.
- OperationService를 통한 재시도 키 사용: 같은 요청 재전송 시 최초 결과를 반환하여 중복 등록 방지.
- 대량 이동 시 기존 조 식별자를 확인해 동시 편성 충돌 감지.
