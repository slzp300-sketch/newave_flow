# NEWAVE 모션 개선 — 2026-10-12

## 적용 내용

- 로그인: 파도 사진이 4.5초 동안 천천히 자리 잡고, 로고·문구·입력 영역이 순서대로 등장한다.
- 홈: 요약 카드와 할 일이 차례로 나타난다. TTS 카드의 파도 선이 그려지고 점수 막대가 채워진다.
- 전체 화면: 페이지 전환 시 짧은 밝기 변화, 공통 카드 등장, 버튼 누름·마우스 반응을 적용한다.
- 메뉴: 카드별 등장 간격을 두고, 하단 메뉴의 선택 배경과 아이콘이 이동한다.
- TTS: 탭 선택 배경 이동, 체크 표시 그리기, 실제 점수 값 전환, 진행 막대와 저장 상태 변화.
- 출석: 학생 카드의 등장 간격을 최대 0.2초로 제한하고 인원 집계 변화에 짧은 효과를 준다.

장식 효과는 반복 재생하지 않는다. 새로운 라이브러리나 이미지 파일을 추가하지 않고 기존 framer-motion과 CSS를 사용한다. 페이지 전체에는 위치 이동 효과를 넣지 않아 고정 제출 버튼·팝업의 기준 위치를 유지한다. 점수 숫자는 중간 값을 만들어 세지 않고 실제 값만 표시한다.

기기의 ‘동작 줄이기’ 설정을 감지해 새 효과를 끄고 기존 Framer Motion의 큰 이동도 줄인다. 검수 환경에서는 같은 설정 값을 강제로 적용해 정적 상태를 확인했다.

## 검수 결과

- 기존 자동 테스트 29개 통과, 배포용 빌드 성공.
- 가상 계정 로그인 후 홈 이동 확인.
- TTS 3회 연속 체크 후 최종 선택·20점·진행률 25% 일치.
- TTS 저장 오류 알림 후 선택과 점수가 기존 상태로 복구됨.
- 가상 출석 3명/불참 1명, 사유 입력, 제출 완료 확인.
- 375px에서 출석 제출 영역과 하단 메뉴의 위치 유지, 문서 가로 넘침 없음.
- 관리자 반 배정 팝업이 화면 기준으로 열리고 취소 후 닫힘.
- 320px·큰글씨·동작 줄이기에서 TTS 세 열 배치와 실제 점수 막대 유지.
- 동작 줄이기에서 로그인 파도·입력 영역·공통 카드의 CSS animation이 none으로 표시됨.
- 검수 탭 콘솔 error 없음.

검수는 실제 컴포넌트와 가상 응답으로 수행했으며 운영 저장·제출은 하지 않았다. 휴대폰 실기기의 체감 부드러움·발열·배터리 사용량은 측정하지 않았다.

API, 권한, 배점, 저장 순서, 데이터베이스, 백업 설정은 변경하지 않았다.
