# TTS 분기 순위 목록 개선

2026-10-29. 사용자가 목록형 시안을 승인하여 정식 1.0.1(8) 소스 기준의 별도 `codex/tts-ranking-list` 브랜치에 구현했다. 스토어 업로드·배포·운영 서버·DB·Android 비공개 테스트는 변경하지 않는다.

- 보기 형식 선택을 제거하고 약 58px의 단일 목록으로 통일한다. 큰 글씨와 긴 이름은 행 높이를 늘려 잘림을 방지한다.
- 전체 순위에서 찾은 본인 행을 앱 헤더 바로 아래에 고정한다. 검색·판정 필터가 본인 행이나 전체 평균·순위를 바꾸지 않는다.
- 연도·분기를 한 선택기에 모으고, 전체 평균·통과·미달·기록 없음 필터와 이름 검색을 보존한다. 조회 중·오프라인·오류에서는 선택 조건과 재시도 안내를 유지한다.
- 이름을 누르면 키보드 포커스를 가두는 상세 창에서 주차별 날짜·체크 항목·최근 저장을 읽기 전용 조회한다. 닫으면 원래 항목과 스크롤로 복귀한다.
- 기존 `/tts/stats/week` GET을 사용한다. 한 번에 열린 주차만 조회하고, 요청 취소 신호와 계정·분기·사람·주차별 캐시 키로 응답을 분리한다. 동명이인은 이름이 아닌 고유 키로 구분한다.
- 날짜별 체크는 선택 분기로 자른다. 분기를 걸친 주의 주간 항목은 전체 주 범위임을 별도 안내한다. 연말의 저장 키가 다음 연도 1주차인 경우도 보존한다.
- 최근 저장은 해당 주의 마지막 수정 시각이며 항목별 클릭 시간이 아니다. 한국 시간으로 표시한다. 시트 점수는 날짜를 추정하지 않고 별도 안내한다.
- 정상 모드 펼침·접힘은 0.28초, 동작 줄이기는 0.16초 불투명도 전환이다. 상세 창의 펼침은 배경 페이지 자동 스크롤과 분리한다.

검증: 프런트엔드 182개 테스트 통과, 네이티브 모드 웹 빌드와 iOS 소스 검증 통과. 5개 신규 테스트는 분기·연도 경계, 일요일, 동명이인, 0점과 기록 없음, 잘못된 주차 응답, 시트 기록, 한국 시간 표시를 검증한다. 실제 컴포넌트를 가상 GET 응답으로 구동하여 고정 행, 필터·검색, 주차 전환, 기록 없음, 시트 안내, 오류 후 정상 조회, 오프라인 후 검색·필터 유지와 연결 복구를 확인했다. 320px 및 120% 글씨에서는 가로 넘침과 컨트롤 잘림이 없으며 체크 날짜·내용을 위아래로 배치한다.

가상 검수: `http://127.0.0.1:5193/.verification/ranking-list-app.html`. 기존 승인 시안은 `ranking-list-preview.html`에 유지한다. 가상 어댑터는 GET만 허용하고 실제 저장을 차단한다.

다음 업데이트 전: 갤럭시·아이폰 설치본에서 고정 영역과 안전 영역, 상세 창 열기·닫기와 뒤로가기, 큰 글씨·동작 줄이기, 운영 API 권한·실제 기록 표시를 확인한다. 개별 체크의 정확한 클릭 시각은 현재 저장 정보로 제공할 수 없다. 이 작업에서는 서버 API와 점수 계산 기준을 바꾸지 않았다.
