# 교사 권한 관리 목록 정리 — 2026-10-29

- 교사 권한 관리는 목록형만 남겼다. 큰 카드·작은 카드·표 보기와 보기 전환 버튼을 제거했고 이전 보기 저장값에 영향을 받지 않는다.
- 목록 항목은 테두리와 일정한 여백을 갖춘 작은 행으로 통일했다. 위에는 이름·현재 권한, 아래에는 소속·이메일을 정렬했다. 오른쪽 화살표와 안내 문구로 항목을 눌러 관리할 수 있음을 표시한다.
- 기존에 세로로 쌓이던 아바타·여백을 줄였다. 375px에서 일반 항목 높이는 약 99~103px, 긴 이메일 항목은 줄바꿈하여 약 122px이다. 고정 높이나 말줄임으로 정보를 숨기지 않는다.
- 이름·이메일 검색, 관리 대상 수, 검색 결과 없음 표시를 유지했다. 검색 중에는 ‘검색 결과’ 수로 표시한다.
- 항목을 누르면 기존 상세 창이 열린다. 권한 변경, 관리자/목사님 최대 2명 제한, 본인 제외, 관리자 전용 권한·비밀번호 기능, 이용 정지 이력 등은 유지했다. 이번 작업에서 API나 백엔드 코드는 변경하지 않았다.

- 기존 프런트엔드 테스트 189개 통과.

- 백엔드 build 성공. 변경이 없어 8개 작업 모두 up-to-date로 확인됐다.
- 가상 자료 브라우저 확인: 목록형 고정, 이전 large/detail 저장값 무시, 이름·이메일 검색과 결과 없음, 상세 창 열기/닫기, 임원 권한 변경 후 목록·상세 갱신, 계정 이력 표시.
- 임원 계정에서는 관리자 계정과 관리자 권한 선택·비밀번호 도구가 노출되지 않는 것을 확인했다.
