## 확정한 기준

- 본인 확인 후 지체 없이 삭제하며 7일 이내 처리를 운영 목표로 삼는다. 법정 기한이라는 뜻은 아니다. 지연 시 사유와 예정일을 개별 안내한다.
- 계정·연락처·프로필·개인 TTS와 관련 개인 활동은 삭제한다. 반 공동 출석·보고서는 요청자의 식별 정보를 제거하고 다른 학생·교사 자료를 보존한다.
- 이 PC의 암호화 DB 백업은 생성 후 30일 보관한다. 만료본은 다음 작업 실행 때 삭제하며 복원 도구에서 사용을 거부한다. PC가 꺼진 동안은 삭제 작업도 실행되지 않는다.
- 복원본을 서비스에 연결하기 전에 삭제 이력을 다시 적용하고 검수한다. 정상 복원 검증은 운영으로의 자동 복원을 뜻하지 않는다.
- 계정 삭제 요청은 앱과 로그인 없는 웹 안내의 이메일로 받는다. 담당자가 본인을 확인하고 처리한다. 자동 접수·즉시 자동 삭제 서비스라고 표시하지 않는다.

## 동의·안내 제안

1. 교사용 가입 안내에서 필수 계정 정보와 선택 프로필 정보를 구분한다. 말씀·기도 등 종교활동 정보는 별도 안내·선택 확인 항목으로 분리한다.
2. 학생·보호자는 앱 계정이 없어도 정보주체다. 학생 자료를 입력하기 전 목적·항목·보관 기간·문의 경로를 설명하는 안내서를 제공한다. 만 14세 미만 포함 여부와 법정대리인 절차를 확인한다.
3. 기존 정보는 이미 동의한 것으로 표시하지 않는다. 안내 전달·동의 등 실제 처리 근거를 확인한 날짜와 범위만 기록한다. 동의하지 않은 사람의 불이익·대체 운영을 교회가 정한다.
4. 주소·사진·세례 여부·상담/기도 내용은 업무상 필요성을 먼저 확인한다. 자유 텍스트에 주민등록번호·신분증·진단서 등을 넣지 않는다. 인앱 동의 수집은 방침과 근거가 확정된 뒤 별도 구현한다.

종교단체의 고유 목적 처리에는 개인정보 보호법 제58조의 일부 적용 제외가 있을 수 있다. 이 앱의 모든 교적·앱 계정·클라우드 처리가 일괄 면제된다고 판단하지 않는다. 제58조 제4항의 최소 처리·보호조치·고충처리 원칙 및 Play 정책을 함께 검토한다. 이 문서는 법률 적합성 확인서가 아니다.

## 외부 처리 확인

- Railway: 운영 서버와 PostgreSQL의 실제 배포 메타데이터 모두 `us-west2`. 공식 지역표와 대조해 미국 보관으로 확인했다. 접속 비밀번호나 실제 행 데이터는 조사에 출력하지 않았다.
- Vercel: 웹 화면 배포·전달. 실제 업무 데이터 API는 Railway로 직접 요청한다. 접속 로그·CDN 처리 국가와 보관 기간은 제공자 설정/계약 확인이 필요하다.
- Google Gmail: 사용자가 권리 행사 이메일을 직접 전송하는 접수 경로. 문의 내용의 서비스 제공자 처리·국외 보관 설명과 보관 기간을 함께 확정해야 한다.
- PC 백업: Windows 사용자에 묶인 DPAPI 암호화, 30일 만료. PC 외 별도 원본·스프레드시트·카카오톡·문서 사본은 담당자가 별도로 조사한다.

## 2026-10-13 운영자 추가 답변

- 처음 방문했을 때 개인정보 처리를 안내하고 본인에게 직접 정보를 받았으나, 별도 동의 기록은 없다. 이를 서면 동의나 민감정보·국외 이전의 개별 동의가 확인된 것으로 표시하지 않는다.
- 기도제목·출결 사유 등에 건강·상담 내용을 기록하는 경우가 있다. 따라서 실제 건강정보 처리를 처리방침과 Play 데이터 보안 신고에 포함해야 한다. 앱에 의료·건강관리 기능이 없다는 선언과는 별개다.
- 만 14세 미만 학생 포함 여부는 답변으로 확인되지 않았다. 성인 교사용 앱이라는 사실만으로 학생·보호자 절차를 생략하지 않는다.
- 다음 작업은 기존 안내 내용을 확인하고, 목적·항목·보관 기간·열람 권한·해외 보관을 적은 새 안내 및 필요한 개별 동의 절차를 정하는 것이다. 실제 확인한 날짜부터 증빙을 남기며 과거 일자로 소급하거나 기존 자료를 일괄 동의 완료로 바꾸지 않는다.
- 건강·상담 원문은 공개 노션·Git·스토어 캡처·심사 계정에 넣지 않는다. 업무에 필요한 최소한의 내용과 제한된 열람 권한을 검토한다. 기존 운영 자료의 일괄 삭제·이관은 이번 준비 작업에 포함하지 않았다.

## 공개 전 남은 확인

표의 보관 기간은 2026-10-12 사용자 승인 완료. 학생·민감정보 처리 근거 및 안내 절차, 외부 제공자 계약·국외 이전의 적용 근거/수령자/연락처/항목/시기·방법/국가/기간/거부 방법, 접속 로그를 확인한다. 삭제 실행은 가상 자료를 사용한 PostgreSQL 검증을 통과했으며, 실제 요청마다 별도 검토·복원본 연습을 거친다. 미확정 사항을 사실처럼 게시하거나 스토어 양식에 확정 답변으로 옮기지 않는다.
