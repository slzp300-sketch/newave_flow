# 회의록 관리: 작은 사분할 카드와 상세 편집

사용자 요청에 따라 회의록 목록은 월별 2열 카드만 표시한다. 기존 큰 카드·목록·표 선택과 저장된 보기 설정은 사용하지 않는다.

- 카드: 날짜, 제목 두 줄, 공개 여부, 영상 유무만 표시. 전체 카드가 상세 창 버튼이다.
- 상세 창: 전체 내용과 영상, 공개 전환, 수정, 참석·회의록 확인 현황, 삭제 확인을 제공한다.
- 수정·등록: 제목·날짜·영상·공개 여부·내용을 입력한다. 저장 실패 시 입력을 유지하고, 미저장 변경을 닫거나 취소할 때 별도 확인한다.
- 참석·확인 명단: 기존 공통 학년별 목록과 이름 펼침 상세를 사용한다. 보기 전환은 제거했다.
- 기존 `/minutes` API와 권한은 유지한다. 저장 시에는 편집 필드만 전송하며 응답 엔티티와 목록 DTO의 공개 속성 이름 차이를 처리한다.
- 네이티브 dialog로 키보드 포커스를 가두고 닫을 때 복원한다. 저장 중 중복 요청·닫기를 막는다.
