# 개인 홈 화면 위젯 — 2026-11-09

## 합의와 범위
- 가까운 일정, 본인의 오늘 영성 체크, 주간 체크 현황.
- 영성 항목은 위젯에서 직접 저장. 출석·투표·행사·회의록은 앱의 해당 화면에서 선택한다.
- 플랫폼 질문의 답변은 없었으며 iOS·Android 모두 준비한다고 사용자에게 알렸다.
- 최적화와 위젯 검증을 마친 뒤 출시한다는 사용자 승인 유지. 이 문서 작성 시 운영 배포·스토어 제출은 진행하지 않았다.

## 구현
- iOS 17 이상: WidgetKit 중간/큰 크기, AppIntent 체크, 일정/주간 항목 링크. 기존 앱 최소 버전은 iOS 15.4 유지.
- Android: RemoteViews 크기 조절, 체크 PendingIntent, 일정/주간 링크, 홈 화면 추가 요청. 검수용 설치는 운영 앱과 다른 식별자를 사용한다.
- 앱 `내 정보 → 홈 화면 위젯`에서 미리보기·추가 안내. 기기의 위젯 갱신 주기는 OS가 관리하며 정확한 시각의 갱신이나 계속되는 백그라운드 실행을 보장하지 않는다.
- 로그인과 앱 복귀·저장 후 위젯 요약을 갱신한다. 같은 계정의 유효한 연결은 재사용하고, 로그아웃/계정 변경 시 캐시를 비운다.
- 서버: `POST /api/widgets/session`, `GET /api/widgets/preview`는 앱 인증. 별도 목적의 위젯 토큰은 `GET /api/widgets/snapshot`, `PUT /api/widgets/check`에만 사용한다.
- 위젯 토큰은 일반 API/로그인 갱신에 사용할 수 없다. 매번 활성 계정·권한 버전·이용 동의 확인. 본인 일정 요약/체크 외 명단·연락처는 보내지 않는다.
- iOS 기본 앱 로그인 키체인은 기존 비공개 그룹을 첫 번째로 유지한다. 위젯 그룹에는 별도 토큰/요약만 저장한다. Android는 별도 키로 암호화하고 백업에서 제외한다.
- 체크는 한국 시간의 오늘 항목만 가능. 기도모임/교사회의 연동 점수를 직접 수정하지 않는다. `PUT /api/tts/answer-fields`는 변경한 날짜만 병합해 앱과 위젯이 다른 날짜를 덮어쓰지 않게 한다. 기존 `/answer`도 유지한다.
- 실패한 쓰기는 자동 재전송하지 않는다. 늦은 응답은 계정·버전 비교로 폐기하며, 오래된 버튼은 다른 계정에 적용하지 않는다.

## 확인
- 서버 위젯 HTTP 검사 6개: 토큰 용도/접근, 로그아웃/역할/이용 동의, 현재 날짜·본인만 변경, 연동 항목 차단, 날짜별 병합.
- 프런트 전체 296개 통과. 위젯 제어기 8개에 로그아웃 중 지연 응답, 계정 변경, 재시작, 중복 갱신, 복귀 시 재연결 포함.
- 웹·네이티브 자산 빌드 및 iOS 소스 검사 통과. iOS 출시 도구 검사 83개 통과. Android 검수 APK 및 lint 통과.
- 375px 가상 자료 미리보기: 위젯 체크 → TTS 월요일 기록 반영, TTS 개인 기도 체크 → 위젯 반영, 기도모임 투표 화면 이동·제출 → 주간 완료 3/4에서 4/4 반영 확인. 큰/중간 크기 가로 넘침 없음.
- 전체 서버 검사에서 낮은 테스트 메모리/여러 Spring 컨텍스트가 같은 H2 DB를 공유하던 문제가 드러났다. 테스트 DB를 컨텍스트별로 분리하고 캐시를 4개로 제한해 전체 빌드를 통과했다(325개 중 305 통과, 별도 PostgreSQL 환경이 필요한 20개 제외). 운영 DB 설정은 바꾸지 않았다.
- Android 실제 기기 암호화 저장·레이아웃 검사, Mac의 Swift 컴파일/키체인 검사 및 서명·실기기 최종 검증은 진행 중이다. HTML 미리보기 성공을 실제 홈 화면 위젯 검증으로 간주하지 않는다.

## 출시 전 남은 일
1. 전체 회귀 검사 및 실제 기기 결과를 이 문서에 업데이트한다.
2. Apple에 `app.newaveflow.mobile.widgets` 확장과 `group.app.newaveflow.mobile.widgets` 그룹을 등록하고 앱/확장 프로파일을 갱신한다. 별도 `IOS_WIDGET_PROFILE_BASE64`가 필요하다. 기존 승인 게이트를 유지한다.
3. 앱과 확장 버전 일치, 확장 서명·전용 키체인 범위·개인 로그인 격리 검사를 통과해야 업로드한다.
4. 기존 미배포 V026/V027은 운영 백업 복원본에서 검증한 뒤 서버부터 적용한다. 위젯은 DB 마이그레이션을 추가하지 않는다.
5. iPhone 화면 잠금/장기 복귀/오프라인·온라인 전환/위젯 직접 저장을 확인한다. Android 공개 출시는 Play 비공개 테스트 조건과 프로덕션 권한을 별도로 확인한다.

## 11월 10일 검증 기록
- 로컬 검증 브랜치 `codex/ios-widget-update`, 초기 구현 커밋 `bde523f`. 운영 main은 변경하지 않았다.
- 공개 저장소 업로드가 자동 승인 검토에서 거절되어 사용자가 **검증 브랜치에 공개 업로드 승인**이라고 명시적으로 답했다. 이 승인은 검증용 코드 업로드이며 스토어 제출 완료를 의미하지 않는다.
