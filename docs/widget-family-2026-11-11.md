# 선택해서 추가하는 위젯 4종 — 2026-11-11

사용자 승인: 영성 체크 / 이번 주 체크 / 일정·체크 / 교회 달력을 각각 골라 추가하도록 개발. 배포하지 않음. 앞선 1~6단계의 미배포 변경은 유지함.

## 반영 내용

- 내 정보 → 홈 화면 위젯: 2×2 종류 선택, 종류별 실제 개인 자료 미리보기, 중간/큰 크기 선택. 교회 달력은 큰 크기만 제공.
- iOS: 하나의 확장 안에 독립 WidgetBundle 항목 4개. Android: 독립 provider 4개와 종류별 선택 목록 설명/미리보기. 여러 종류와 같은 종류 여러 개를 함께 추가할 수 있음.
- 기존 `NewavePersonalWidget` 및 Android `NewaveWidgetProvider` 식별자는 일정·체크에 유지. 새로운 앱 선택 값은 기존 설치 위젯의 종류를 덮어쓰지 않음.
- Android 추가 버튼은 선택한 provider로 시스템 추가 창을 요청. iOS는 선택한 이름으로 시스템 위젯 갤러리에서 추가하는 경로를 안내. 앱 화면의 크기 선택은 미리보기이며 실제 크기는 시스템 추가/크기 조절에서 결정됨.
- 영성 체크: 넓은 체크 영역과 저장 후 확인된 상태 표시. 앱 미리보기에서는 TTS로 이동하고, 실제 홈 화면 위젯에서는 전용 체크 요청을 사용.
- 이번 주 체크: 해당 교사의 `pending` 항목만 표시. 완료/비대상은 제외. 공간보다 많은 경우 남은 개수와 홈으로 가는 버튼 표시. 각각의 항목은 기존 화면으로 연결.
- 일정·체크: 가까운 일정, 오늘 영성 체크, 남은 주간 체크. 큰 크기는 남은 항목도 표시.
- 교회 달력: 이번 달 달력, 오늘 표시, 일정 날짜 점, 가까운 일정 2개. 달력 영역을 누르면 앱 달력, 일정을 누르면 해당 날짜로 이동. 개인 외부 캘린더 연동/추가 권한 없음.
- 서버 snapshot v1에 `calendarDates`를 추가. 현재 월의 전체 교회 일정 날짜를 제공하되 최대 31개, 중복 제거, 지난 일정 및 여러 날 일정/월 경계를 포함. 제목·내용·참석자 상세는 추가하지 않음. 기존 `events`는 가까운 3개 유지.
- 예전 snapshot에는 날짜 필드가 없어도 읽을 수 있음. 날짜 표시를 임의로 만들어내지 않고 갱신 안내. 계정 분리, 로그아웃 폐기, 오래된 응답 방어, 실패한 체크 자동 재전송 금지는 유지.
- 공유 자료 변경 시 네 종류 갱신. iOS 체크를 누른 종류는 시스템이 새로 표시하고 다른 종류는 명시적으로 갱신. 최근 확인된 snapshot은 재사용해 같은 체크 후 추가 요청을 줄임. [Apple 위젯 갱신 문서](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date).
- Android 갤러리와 앱 내 추가는 provider 단위로 분리. [Android 위젯 추가 문서](https://developer.android.com/develop/ui/views/appwidgets/discoverability).
