# 중보기도팀 구현 기록 — 2026-11-04

확정된 시안을 실제 앱·서버에 구현했다. 운영 자료 변경, 배포, 커밋·푸시, 스토어 제출은 하지 않았다. 기존 홈 구조·파트별 색상 수정도 보존했다.

## 완료 범위

- 담당 업무와 임원 내 업무에 중보기도팀 연결. 일반 교사는 기존 기도모임 화면에서 기도제목·모임으로 이동한다.
- 기존 화·목 참석 투표의 주차와 집계를 재사용한다. 참석 투표를 실제 출석으로 계산하지 않는다.
- 화·목별 시작 시간, 30/45/60분, 진행자, Zoom HTTPS 주소를 저장한다. 시작 시간은 운영자가 정하며 임의의 고정 시간을 넣지 않았다.
- 조직도의 현재 활동연도 중보기도팀장을 자동 연결한다. 관리자·목사·팀장은 팀원을 지정하고, 팀원도 접수·정리·공유·모임 준비를 한다.
- 교사 직접 제출과 팀의 카톡 대리 등록. 분류, 전체 공유 여부, 익명 여부를 저장한다. 원문과 공유 제목·본문은 별도 필드다.
- 새 요청·공유 중·팀 전용·전체 접수 목록, 내 제출 목록, 전체 공유 게시판, 응답·감사, 검색과 페이지 이동.
- 정리 저장, 전체 공유, 공유 내용 수정, 응답·감사 이동, 본인 또는 팀의 철회.
- 공개된 제목만 모임별로 선택하고 순서를 저장한다. 공유본 생성, 복사, 큰 글씨 화면, 이전·다음과 글씨 크기 조절.
- 기존 앱의 선택 목록·모달·완료 알림·동작 줄이기를 사용한다. 담당 업무의 보라색 제목과 작은 카드 크기를 적용했다.

## 저장·권한

- 실제 경로는 /intercession, API는 /api/intercession이다.
- V022__intercession_team.sql: 팀원·명단 버전·기도제목·날짜별 모임과 공유본을 추가한다.
- 모든 쓰기는 계정 상태 변경과 같은 순서로 계정 잠금을 확보하고, 현재 권한과 로그인 버전을 다시 확인한다.
- 명단, 기도제목, 모임에 변경 버전을 검사한다. 오래된 화면의 덮어쓰기는 거절하고 입력 내용을 남긴다.
- 전체 공유 응답에는 원문·접수 경로를 포함하지 않는다. 익명 제출자의 이름은 팀 편집으로 다시 공개할 수 없다.
- 팀 전용 요청과 철회된 요청은 공개 자료에 넣을 수 없다. 자료 원본이 수정·철회·응답 처리되면 이전 공유본을 반환하지 않고 다시 만들도록 한다.
- API 응답은 no-store. 공개 목록의 검색도 공개 필드만 조회한다.
- 계정 삭제 절차에 요청 본문·팀원·진행자·Zoom 링크와 저장된 자료 사본 처리를 추가했다. 다른 작성자의 공동 내용은 기존 본문 검토 절차에 포함한다.

- 개인정보 삭제 PostgreSQL 검사 1개 통과: 새 기도제목·팀원·자료 사본 처리 및 다른 교사의 요청 보존을 포함한다.

- 팀원 추가, 진행자 변경, 시간 변경, 기존 투표 화면 반영, 새로고침 후 저장 유지 확인.
- 320px·375px 화면 넘침 없음, 1100px 발표 화면 확인. 실제 iPhone/Android 설치 검수나 실제 Zoom 회의 입장 확인은 이번 범위에 포함하지 않았다.

## 로컬 미리보기

- 팀장: http://127.0.0.1:5202/.verification/intercession-live-app.html?role=LEADER
- 교사: http://127.0.0.1:5202/.verification/intercession-live-app.html?role=TEACHER
- 팀원: 같은 주소의 role=TEAM
- 기존 투표: 같은 주소의 page=vote

8094의 가상 자료 전용 H2 서버와 5202 화면 서버를 사용한다. 입력은 새로고침 시 유지되고 검증 서버 재시작 시 초기화된다. 실제 앱의 저장은 설정된 서버 데이터베이스를 사용한다. 미리보기의 22:00과 진행자는 입력 검증을 위한 가상 설정이다.

시안 전용 5201 페이지는 기존대로 보존했다. 새 미리보기는 시안의 메모리 상태를 흉내 내는 화면이 아니라 실제 페이지·API·권한·저장 코드를 실행한다.
