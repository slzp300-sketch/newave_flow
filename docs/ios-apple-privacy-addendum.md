# Apple 로그인 활성화 전 개인정보 안내 추가안

작성: 2026-10-15. **현재 Apple 로그인은 기본 비활성이다. 이 문서는 공개 방침에 아직 적용하지 않은 준비안이다.** Apple 계정 활성화·서명 설정만으로 자동 게시하지 않는다.

## 공개 방침에 추가할 문구

### 처리 항목·목적

> Apple로 로그인을 선택하면 Apple 계정의 앱별 식별자를 인증 및 계정 연결에 사용합니다. Apple이 최초 승인 때 이름·이메일을 제공할 수 있지만 현재 앱은 이 값을 가입 양식에 자동 입력하거나 서버 계정에 자동 반영하지 않습니다. 신규 가입 화면에서 이용자가 직접 입력·확인한 이름·이메일과 선택 연락처를 계정에 저장합니다. Apple 프로필 사진이나 연락처 목록을 가져오지 않습니다. 일반 이메일 로그인도 계속 이용할 수 있습니다.
>
> Apple 인증 코드·신원 확인 토큰은 인증을 확인하는 동안 처리하며, 연결 관리와 철회를 위해 갱신 토큰을 서버에서 암호화해 보관합니다. 인증 중에는 상태·nonce 해시·PKCE 확인값·만료시각 등 위조 방지 정보를 잠시 저장합니다. 원문 토큰과 인증 응답을 운영 로그에 남기지 않습니다.

### 보관·연결 철회·삭제

> 인증 진행 정보는 최대 5분 동안 유효하며 만료된 서버 자료는 정기 정리합니다. 계정 연결 식별자와 암호화 갱신 토큰은 연결 관리에 필요한 동안 보관합니다. 계정 삭제 요청에서 Apple 인증 권한을 철회한 뒤 갱신 토큰을 제거하고, 실제 앱 계정 삭제 때 해당 연결 자료를 삭제합니다. Apple 연결 상태가 바뀌면 앱의 로그인 세션을 종료할 수 있습니다.
>
> Apple이 보내는 동의 철회·Apple 계정 삭제 알림의 진위를 확인하고 중복 처리를 막기 위해 앱 범위의 식별자 해시·알림 ID 해시·본문 해시·수신/철회/처리 시각을 저장합니다. 알림 원문을 별도로 보관하지 않습니다. 알림 접수 해시는 수신 후 30일을 기준으로 정리하며, 계정과 연결된 상태 기록은 해당 계정 관리에 필요한 동안 보관합니다. 계정 연결이 없는 상태 기록은 마지막 갱신 후 30일을 기준으로 정리합니다. Apple 계정의 삭제 알림만으로 공동 업무 자료를 즉시 삭제하지 않으며 앱 계정의 삭제 요청·실제 처리와 구분해 안내합니다.

### 외부 서비스 안내

> Apple Inc.는 이용자가 선택한 Apple 인증을 제공합니다. Apple 계정과 인증 서비스의 처리는 Apple 개인정보 보호정책을 따릅니다. 앱은 필요한 인증 결과와 계정 연결 자료를 위 목적에 사용합니다. [Apple 개인정보 보호정책](https://www.apple.com/legal/privacy/kr/)

이 문구는 기능 설명에 대한 준비안이다. 국외 이전 표에 넣을 실제 수령자 연락 방법·처리 지역·이전 근거는 활성화 당시 Apple의 해당 계약·공식 정책과 운영 조건을 대조해 작성한다. 서버의 기존 미국 보관 안내가 Apple 제공자의 모든 처리 국가를 대신하지 않는다.

## 적용 전 확인할 사항

1. `AppleAuthService`는 신원 확인·코드 교환 후 subject와 암호화 갱신 토큰을 저장한다. 신규 가입 이름·이메일은 가입 양식에서 이용자가 직접 입력한 값이다. `appleFlow.js`는 네이티브의 이름·이메일을 서버에 넘기거나 양식에 채우지 않는다. Apple 이메일 가리기를 선택한 것만으로 앱 계정의 이메일도 자동 변경된다고 설명하지 않는다.
2. `NewaveAppleSignInPlugin`은 이름·이메일 scope를 요청한다. Apple은 이름·이메일을 매번 주지 않을 수 있으므로 해당 필드의 재수신을 약속하지 않는다.
3. `AppleAuthFlow`는 300초 유효하고 만료 자료 정리 작업은 60초 간격이다. ‘5분이 되는 순간 모든 사본 완전 삭제’로 표현하지 않는다.
4. `AppleNotificationStateStore`는 30일 기준 정리를 매시간 실행한다. 수신 원문 대신 해시를 보관해도 계정 연결이 있으므로 App Privacy에서 처음부터 비연결 데이터라고 답하지 않는다.
5. V011 운영 적용·Apple 알림 주소 등록·서명 검증·철회 후 세션 차단·새 연결·삭제 요청을 합성 계정과 최종 iPhone에서 검증한다. Apple 로그인 OFF 경로에는 이 미적용 스키마를 요구하지 않는다.
6. Name·Email Address·User ID 및 상태 처리의 Other Data Types에 Apple 경로를 포함한다. 목적은 App Functionality, 연결됨 예, 추적 아니오를 유지할 수 있는지 최종 구성을 대조한다.
7. 활성화할 때 공개 방침 시행일과 변경 안내를 갱신하고 한국어 공개 HTML을 재생성해 앱·웹의 동일 문구를 확인한다. Apple 로그인 안내·심사 노트·심사 접근도 같은 빌드 상태로 변경한다.
