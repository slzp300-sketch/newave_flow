- 기존 필수 입력 검사, 폼 값, React 변경 이벤트, 숫자/빈 값/문자열 false, 비활성 항목, 상위 fieldset의 입력 잠금을 보존. 숨겨진 선택기는 탭 순서와 접근성 트리에서 제외하고 오류 시 보이는 선택 버튼에 초점을 이동.
