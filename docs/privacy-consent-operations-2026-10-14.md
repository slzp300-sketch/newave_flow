# 개인정보 안내·개별 동의 운영 양식

방침 버전: 2026-10-14. 운영: 제자광성교회 뉴웨이브 청소년부 / 담당자: 김재현 / 문의: slzp300@gmail.com. 공개 방침: `https://newave-flow.vercel.app/privacy`. 원본: `frontend/src/content/privacyPolicy.js`.

운영자는 학생 범위 중1~고3, 외부 판매 없음과 새 안내·필요한 개별 동의를 **실제 확인 날짜부터 기록**하는 절차를 승인했다. 이 양식 준비가 실제 대상자의 동의 수집 완료를 뜻하지 않는다. 기존 자료를 일괄 동의 완료로 표시하거나 과거 날짜로 소급하지 않는다. 앱 안에서 동의를 자동 수집·저장하는 기능은 아직 없다.

## 항목별 안내와 선택

각 동의에 `[ ] 동의  [ ] 동의하지 않음`을 따로 표시한다. 미리 선택하지 않는다. 방침 열람 확인으로 개별 동의를 대신하지 않는다. 학생 정보와 보호자 자신의 정보도 구분한다.

## 미국 이전·보관 — 별도 동의

대상별로 이전할 항목에 표시하고 다음 내용을 전달한다. 학생 자료에 교사 계정의 서비스 계약을 일괄 적용하지 않는다.

- 수령자·연락처: Railway Corporation / privacy@railway.com.
- 국가: 미국, 실제 API·DB 지역 `us-west2`.
- 목적: 앱 API 제공, 계정·반·활동 자료 저장, 서비스 보안.
- 항목: 위 표 중 해당 대상자가 동의하거나 다른 근거가 확인된 항목만 표시. API 접속 IP·시각·경로·상태 등 운영 기록이 처리될 수 있음을 함께 안내.
- 시기·방법: 입력·수정·조회와 서비스 운영 시 HTTPS 등 암호화된 네트워크 전달·저장.
- 기간: 위 항목별 기준, 삭제·익명 처리 또는 서비스 종료에 따라 업무 자료 정리. 제공자 자체 보안·운영 기록은 제공자의 서비스·법률상 필요 기간과 공개 정책에 따름.
- 거부·철회: slzp300@gmail.com 또는 담당자에게 직접 요청. 해당 자료의 미국 서버 저장 기능 이용은 어려울 수 있음. 그 항목의 신규 입력을 중단하고 직접 연락·대면 방식으로 필요한 업무 진행.
- 선택: `[ ] 위 표시 항목의 미국 이전·보관에 동의  [ ] 동의하지 않음` / 실제 선택일 / 안내문 버전.

웹 방문 시 Vercel 미국 및 글로벌 전달망에서 접속 정보가 처리된다. 업무 API는 Railway로 직접 연결된다. 선택한 Gmail 문의는 Google 미국 및 전 세계 데이터센터에서 발신자·문의 내용을 처리할 수 있다. 교회 접수 메일은 처리 완료 후 90일 기준이며 제공자 자체 기록은 각 정책을 따른다. 특정 단일 국가·고정 완전 삭제 일수를 보장하는 서비스로 설명하지 않는다. 담당자에게 직접 문의·권리를 행사하는 방법도 안내한다. 공개 방침 5절과 제공자 정책을 함께 전달한다.

## 만 14세 미만 법정대리인 확인

1. 한국식 나이·학년 대신 생년월일 기준 **안내·동의일의 만 나이**를 확인한다.
2. 학생에게도 쉽게 설명한다. 만 14세 미만의 동의가 필요한 처리는 법정대리인에게 기본 정보·종교활동·건강정보·국외 이전을 각각 안내한다.
3. 법정대리인 이름·학생과의 관계·연락처를 필요한 범위로 확인한다. 보호자라는 이유만으로 법정대리인으로 추정하지 않는다. 대면 또는 기존 확인된 연락 경로로 실제 선택 여부를 확인하고 서명된 안내서/동의서 등의 증빙을 제한된 운영 보관소에 둔다. 확인이 부족하면 입력을 보류한다.
4. 신분증·주민등록번호·가족관계 서류 사본을 기본 증빙으로 요구하지 않는다. 추가 확인이 꼭 필요하면 원문 보관 대신 최소 확인 결과를 남긴다.
5. 확인일·방법·설명자·방침 버전을 기록한다. 실제 명단·종교/건강 내용·동의서는 공개 Git·노션 작업로그·스토어 심사 계정에 넣지 않는다.
