# 임원 업무·조직도 — 2026-11-03

상태: 로컬 구현 및 검증. 운영 배포, 운영 계정 지정, 앱스토어 제출은 하지 않음.

## 이번 범위

사용자가 승인한 순서 중 1~3단계를 구현했다. 새 팀 기능은 사용자의 “팀별 세부 업무를 설명한 뒤 개발” 결정에 따라 보류한다.

1. 연도별 18개 직책과 담당자 지정
2. 임원 업무 홈, 공통 관리, 조직도
3. 서기의 기존 주간보고서, 새가족팀장의 기존 새가족 관리, 학년부장의 학년 출석 현황 연결

직책: 목사 / 부장 / 부감(남·여) / 총무·부총무·회계·서기 / 중보기도·찬양·예배운영·새가족 팀장 / 중1~고3 학년부장. 직책은 18자리이며 겸직을 지원한다. 담당 인원은 중복 없이 별도로 계산한다. 성별이나 프로필의 직분 문자열로 담당자를 자동 추정하지 않는다.

## 동작과 권한

| 기능 | 이용 범위 |
| --- | --- |
| 공통 관리·출석 보완 | 기존 ADMIN / PASTOR / EXECUTIVE |
| 조직도 조회 | 위와 동일 |
| 담당자 지정·활동연도 전환·변경 기록 | ADMIN |
| 주간보고서 공통 항목·미리보기·출력 | 활동연도 서기 + ADMIN / PASTOR |
| 새가족 출결·과정·등반 요청 | 활동연도 새가족팀장 + 기존 지정 팀원 + ADMIN / PASTOR |
| 새가족팀원 지정·최종 반 배정 | 기존 ADMIN / PASTOR 정책 유지 |

- 개인 출석·기도모임/교사회의 투표·TTS는 기존 경로를 유지한다.
- 학년부장은 내 업무에서 담당 학년으로 바로 진입한다. 공통 관리 권한은 다른 임원과 같으므로 다른 학년도 조회·보완할 수 있다.
- 보고서 작성·출력과 일반 출석 관리를 분리했다. 공통 출석 조회 및 보완 응답에는 보고서 공통 항목, 헌금, 출력 기록을 반환하지 않는다.
- 화면 표시뿐 아니라 서버에서 직책을 다시 확인한다. 직책 해제 후 보고서 조회·저장·미리보기·출력 요청 및 새가족 접근이 차단된다.
- ADMIN/PASTOR는 기존 전체 접근을 유지한다. 목사 직책에는 PASTOR 권한 계정만 지정할 수 있다.

## 연도·계정 처리

- 다음 연도 인선을 준비해도 현재 권한은 바뀌지 않는다. 명시적으로 활동연도를 전환해야 적용된다.
- 전환 직전에 정지·미승인·삭제 요청 계정과 목사 권한을 다시 검사한다. 잘못된 인선이 있으면 전환 전체를 거부한다.
- 현재 활동연도에 일반 교사를 지정하면 임원 권한과 재로그인이 필요하다. 조직도로 자동 승격된 계정은 마지막 활성 직책 해제 시 교사로 돌아간다.
- 기존에 별도로 부여한 임원·목사·관리자 권한은 직책 해제로 낮추지 않는다. 기존 역할 변경 화면에서 임원으로 명시 지정한 경우도 별도 부여로 취급한다.
- 활성 직책을 가진 계정을 교사로 낮추려면 먼저 직책을 해제해야 한다.
- 변경 요청에는 조직도 버전을 포함한다. 오래된 화면의 저장은 409로 거부한다. 계정 상태 변경과 동일한 순서로 잠금을 잡아 권한 변경을 직렬화한다.
- 삭제된 계정의 조직도 자리는 공석으로 남기며 변경 이력의 계정 연결을 제거한다. 이름 사본을 별도 저장하지 않는다.

## 검증

- 프런트 전체 시험 237개 통과, 앱용 Vite 빌드 성공. 기존의 큰 번들·혼합 import 경고는 남아 있다.
- 서버 전체 빌드 성공: 268개 중 252개 통과, 외부 환경이 필요한 조건부 시험 16개 제외. 별도 실행한 조직도 PostgreSQL 시험 1개도 통과했다.
- 별도 로컬 PostgreSQL에서 V020 적용, 오류 시 전체 롤백, 재실행 거부, 겸직·직책 유일성, 기존 역할·팀원 유지, 삭제 FK 처리와 Hibernate 스키마 검증 통과.
- 가상 자료를 사용하는 실제 서버·화면 연결로 담당자 저장 및 인원·변경 기록 갱신을 확인했다.
- 서기 공통 항목 저장 후 새로고침에도 값 유지, 중1 학년부장 기본 필터, 새가족팀장 기존 화면 진입, 일반 임원의 보고서 직접 접근 차단을 확인했다.
- 320px 작은 화면 및 큰 글씨 조직도에서 가로 넘침 없음. 서기 조직도에는 편집 버튼이 없음.
- 운영 자료나 외부 서비스는 이 검증에 사용하지 않았다.
