# 출석·주간보고서·새가족 화면 디자인 정리

기존 앱의 `brand-theme.js`, `design-tokens.css`, `interactions.css`와 공통 Button/FeatureIcon 기준으로 새 업무 화면을 정리했다. 배포하지 않았다.

## 반영 내용

- 교사 출석: 작은 학생 카드와 목록을 유지하면서 공통 색상·16px 카드 곡률·12px 입력란 곡률을 적용. 출석 요약을 세 구획으로 구분하고, 메모 버튼도 44px 터치 영역 확보. 검색창 내부에 별도 테두리가 겹치던 스타일 제거.
- 주간보고서: 취합 현황을 세 구획으로 표시. 보완 영역·입력란·다운로드 버튼을 기존 앱과 통일. 공통 Button 사용으로 헤더·주 이동 버튼을 덮어쓰던 페이지 전체 버튼 스타일 제거.
- 새가족: 탭·학생 카드·상태 배지·4주 진행 표시·등록/등반/반 배정 폼을 공통 색상과 형태에 맞춤. 출결 요약은 네 구획으로 표시.
- 기존 메뉴와 같은 Lucide 아이콘 체계에 새가족팀과 주간보고서 아이콘 추가.
- 불참 선택은 공통 `data-tone="absence"` 규칙으로 붉은색, 일반 선택은 초록색, 주요 실행 버튼은 파란색 사용.
- 숫자 요약에 공통 `ui-metrics`와 의미 있는 dl/dt/dd 마크업 사용. rem 기반 크기로 큰 글씨 모드 지원.

## 확인

- `npm test`: 194/194 통과.
- `npm run build -- --outDir .verification/design-alignment-build`: 성공. 기존 청크 크기/혼합 import 경고만 있음. 추적 중인 `frontend/dist` 변경 없음.
- 실제 React 화면 + 로컬 가상 DB에서 브라우저 확인. 320px 화면에서 출석 선택·불참 사유 입력, 새가족 등록 폼 입력, 보고서 보완 폼을 확인했으며 문서 가로 넘침 없음.
- 320px + 큰 글씨 120%에서 교사 출석·추가 정보, 새가족 목록·과정 날짜 입력, 보고서 보완 폼의 가로 넘침 없음. 입력 글꼴은 19.2px로 확대됨.
- 출석 버튼과 메모 버튼의 터치 높이 44px 이상 확인. 불참 선택의 붉은 상태 표시 확인.
- 보고서 보완 내용을 입력하면 다운로드가 비활성화되고 작성 취소 후 기존 자료로 돌아오는 동작 확인.
- 화면 미리보기의 보고서 iframe, 자동 집계 서비스, HWPX/PDF 생성기와 원본 양식은 변경하지 않음. 이번 작업에서는 파일 재다운로드나 실제 기기 검증을 반복하지 않음.

## 추가 보완: 담당 반 표시와 펼침 버튼

- 반 선택이 보이던 원인은 가상 교사 한 명에게 여섯 반을 배정한 테스트 데이터였다. `/api/classes`는 역할과 무관하게 본인의 실제 배정만 반환하며, 선택창은 두 반 이상일 때만 표시한다.
- 8090/8091 로컬 가상 DB의 가상담임은 중1반 한 개만 담당하도록 정리했다. 재시작용 fixture도 동일하게 수정. 운영 데이터는 변경하지 않았다.
- 여러 반을 실제로 담당할 때의 이름은 ‘담당 반 전환’으로 명확히 하고, 본인에게 배정된 반만 나온다는 설명을 추가했다. 한 반 담당 화면에서는 선택창 없이 바로 입력한다.
- 새 업무 화면의 모든 native details/summary에 `DisclosureSummary`를 적용했다. 오른쪽 ChevronDown, 둥근 테두리, 동일한 여백, 열린 상태의 초록색과 화살표 회전을 사용한다. 폼은 닫아도 마운트된 상태를 유지한다.
- 기존 공통 Motion Disclosure도 같은 버튼 디자인을 사용한다. 앱 공통 선택 색상 규칙에 aria-expanded를 포함해 다른 펼침 버튼도 열린 상태를 일관되게 표시한다.
- 확인: 한 반 선택창 0개, 비담당 2번 반 학생 조회 403, Enter/Space로 접기·펼치기와 입력 내용 유지, 보고서와 새가족 펼침 영역의 초록색/화살표 회전, 가로 넘침 없음. 프런트엔드 테스트 194개 통과.

## 추가 보완: 앱 안내 문구 간소화

- 사용자 요청에 따라 앱의 사용법 설명은 짧은 문구 중심으로 작성한다. 이미 제목·버튼에서 알 수 있는 설명과 반복되는 교육용 문장은 제거한다.
- 주간보고서 상단은 ‘교사·새가족팀 자료 자동 집계’로 단축하고, 새가족 관리 링크와 취합 현황을 바로 보여준다. 보완·다운로드·출력 기록의 안내도 축약했다.
- 출석·새가족의 등록/과정/등반/배정, 가입 승인·학생·반 관리, 일정·행사, TTS, 계정 연결·가입, 사진·신고, 앱 이용 안내까지 표시 문구를 정리했다.
- 미저장·재제출·적용일·팀 판단·비공개 범위 등 작업 결과를 이해하는 데 필요한 정보는 간결하게 유지했다. 기능, 권한, 집계와 문서 양식은 변경하지 않았다.
- 검증: 프런트엔드 테스트 194개 통과. `.verification/concise-copy-build` 별도 경로 빌드 성공(기존 청크 크기·혼합 import 경고만 존재).
- 실제 로컬 React 화면에서 보고서 상단, 교사 출석·추가 정보 펼침, 새가족 4주 과정의 문구와 배치를 확인했다. 세 화면 모두 434px 뷰포트에서 가로 넘침이 없었다.
- 운영 자료 변경, 배포, PR 생성 없이 로컬 수정만 반영했다.
