# 찬양팀 운영 계획·시안 — 2026-11-03

상태: 아래 시안 승인 후 확정 범위의 앱·서버 구현과 로컬 검증을 완료했다. 운영 자료 적용과 출시는 하지 않았다. 구현·검증 및 출시 전 남은 확인은 [개발 기록](praise-team-implementation-2026-11-03.md)을 참고한다. 아래 시안 이력의 ‘제품 코드 미변경’ 설명은 각 시안 단계 당시 상태다.

## 사용자 확정 사항

- 구성은 찬양팀장, 찬양팀 교사, 찬양팀 학생이다.
- 학생 본인 화면은 추후 개발한다. 팀장은 현재도 교사·학생 명단과 배정을 관리해야 한다.
- 토요일/주일 모임·연습을 진행하며 팀장이 매월 로테이션을 편성·공유한다.
- 파트는 첨부 표의 인도자, 메인, 세컨, 일렉, 베이스, 드럼, 싱어, 워십을 기준으로 한다. 싱어·워십은 여러 명이다.
- 교사는 본인 배정을 확인하고 미리 콘티를 숙지해 참여한다.
- 콘티는 PDF이며 인도자가 화요일, 늦어도 수요일까지 공유한다.
- 콘티 열람 여부 체크는 사용하지 않는다. 확인 버튼·개인별 열람 기록·미확인자 관리·재확인 요청을 기능 범위에서 제외한다.
- 학생이 인도하는 주에는 찬양팀장이 학생과 연락한 뒤 콘티를 공유한다. 일반 교사에게 자동 대행 권한을 주지 않는다.
- 목요일 Zoom 기도회는 22:30–23:00, 교사가 돌아가며 개설·진행한다. 진행자 로테이션은 반기별로 편성한다.
- 상반기: 2월 한 달 훈련, 3–7월 다섯 달 예배 활동.
- 하반기: 시작 시 재결단·모집, 9월 한 달 훈련, 10–12월 세 달 예배 활동.
- 다음 달 로테이션 편성 전에 **토요일 연습 참여 불가 날짜만** 받는다. 주일 예배 불가는 별도로 받지 않는다.
- 기본 연습 시간은 토요일 17:00–19:00이며 팀장이 교회 일정에 맞춰 각 주차의 시간을 변경한다.

홈 메뉴에서 업무별 전용 화면으로 이동한다. 화면마다 제목·상위 목록으로 돌아가기·홈 버튼을 표시한다. 로테이션은 배정, 콘티 자료실은 PDF 공유, 목요 기도회는 진행자 편성에 집중한다. 같은 주의 로테이션과 콘티는 서로 바로 이동할 수 있다.

기존 앱의 작은 통계 카드, 목록, 선택 메뉴, 펼침 버튼을 재사용한다. 월간 표는 첨부 형식을 따라 전체 배정을 비교하고, 휴대폰에서는 주차별 카드를 눌러 별도 상세 화면을 본다.

## 데이터와 권한 설계 제안

- 조직도의 PRAISE 직책으로 팀장 권한을 연결한다. ADMIN/PASTOR 전체 접근 정책은 유지한다.
- 팀원은 기존 계정/학생을 참조한다. 프로필 직분 문자열·이름으로 권한을 추정하지 않는다.
- 학기 소속, 담당 가능한 복수 파트, 활동 상태는 기본 교적 정보와 분리한다.
- 예배 날짜를 주차 기준으로 하고 연습 날짜·시간은 별도로 저장한다. 토요일 연습과 주일 아침 연습을 모두 표현한다. 월 경계의 연습은 다른 달일 수 있다.
- 교사는 본인이 교사 인도자로 배정된 주의 PDF만 올린다. 학생 인도 주는 팀장만 대행한다. 팀장의 관리 수정은 허용한다.
- 월간 배정은 초안/공개를 구분한다. 교사에게는 공개본만 보이고 변경된 배정은 표시한다.
- 같은 시각의 중복 배정·비활동 팀원·미배정 파트를 확인한다. 인도와 싱어 등 가능한 겸임까지 일률적으로 차단하지 않는다.
- 명단에서 활동을 해제해도 과거 배정·콘티·학기 기록은 보존한다. 이후 일정의 남은 배정은 팀장이 확인한다.
- 콘티는 공유된 PDF를 자유롭게 열어보는 흐름이다. 교체된 파일의 버전과 공유 정보만 표시하며, 교사별 읽음 상태나 확인률을 기록·표시하지 않는다.
- PDF는 파일 형식·크기 검사, 비공개 저장, 권한 있는 내려받기, 교체 기록이 필요하다. 앱 내부 보기와 내려받기를 기기별 확인한다.
- Zoom 회의 자체는 담당 교사가 개설한다. 앱은 진행 일정·진행자·참여 링크를 관리한다. 기도회 로테이션과 예배 파트 로테이션은 별개로 보관한다.
- 학생 계정의 직접 업로드·로그인 기능은 이번 범위에서 제외한다.

- 학생 인도 시 PDF 공유 담당자는 확정되었지만 연락 내용 자체를 앱에 기록하는 기능은 요청되지 않았다.
- 콘티 수정 알림의 방식, 연습 불참/대타 요청, 출석 통계는 별도 설명 후 범위를 정한다. 현재 계획에 자동 벌점·숙지 평가를 추가하지 않는다.

- 역할 전환은 시안 비교용이다. 실제 권한 집행, 미공개본 접근 제한, 파일 검증은 제품 개발 때 서버에서 구현·시험해야 한다.

## 50명 규모 명단 개선 — 2026-11-03

사용자가 교사·학생을 합쳐 약 50명이라고 설명했다. 기존 한 사람당 넓은 행을 사용하는 시안을 이름 중심의 2열 목록으로 변경했다.

- 기본 '구성별': 교사와 학생 학년(중1~고3)별 그룹. 그룹 인원을 표시하며 각각 접거나 전체 접기/펼치기가 가능하다.
- '파트별': 인도자~워십별 그룹. 겸임자는 해당 파트에 각각 표시하지만 전체/검색 인원은 사람 기준으로 계산한다. '겸임 포함'을 짧게 표시한다.
- 전체·교사·학생을 인원 숫자와 함께 즉시 전환한다. 별도 큰 인원 통계 카드를 제거했다.
- 이름과 짧은 파트 정보만 기본 표시한다. 이름을 누르면 구분·학년·전체 파트·월별 배정을 확인한다.
- 이름 검색은 선택한 대상 안에서 작동한다. 검색하면 해당 이름이 있는 그룹이 펼쳐진다. 검색 결과 없음도 표시한다.
- 팀원 지정과 주별 파트 배정에도 같은 검색·그룹·2열 선택 목록을 사용한다. 필터가 바뀌어도 기존 선택은 유지된다.
- 교사 12명·학생 38명은 **가상 자료의 구성**이며 실제 비율을 추정한 값이 아니다. 총 50명으로 크기를 검토했다.
- 확인: 50명 렌더링, 교사/6개 학년 그룹, 320px 화면에서 가로 넘침 없음, 이름별 터치 영역 최소 44px, 이름 검색과 상세 배정, 파트 겸임자의 검색 인원 중복 방지, 선택 목록에서 숨겨진 선택 유지.
- 권장: 일반 확인은 구성별, 편성 작업은 파트별. 시안만 변경했으며 제품 코드·실제 명단·배포에는 반영하지 않았다.

## 업무별 화면 분리 — 2026-11-03

사용자가 한 페이지에서 모든 업무를 진행해 구분이 어렵다고 피드백했다. 상단 탭과 중첩 탭을 제거하고 찬양팀 홈 → 5개 전용 화면 → 주차 상세 흐름으로 변경했다.

- 홈에는 이번 주 연습·파트별 배정·콘티 공유 정보·목요 기도회를 펼쳐 표시한다. 별도 상세 진입 없이 내용을 확인하고, PDF는 홈에서 바로 연다. 명단·편성·공유 관리 등 업무 메뉴는 아래에 유지한다.
- 명단은 기존 50명 규모의 검색·그룹·2열 목록을 유지한다.
- 예배 로테이션과 목요 기도회 편성을 별도 화면으로 분리했다. 콘티 공유도 자료실에서만 진행한다.
- 화면별 주소, 제목, 상위 목록·홈 이동을 제공한다. 브라우저 뒤로가기와 주차 상세 새로고침을 지원한다.
- 확인: 홈 메뉴 이동, 로테이션→같은 주 콘티→브라우저 뒤로가기, 주차 상세 새로고침, 명단 50명·이름 검색, 320px 홈/명단 가로 넘침 없음, 목요 기도회·학기 운영 분리, 교사 본인 인도 주 PDF 보기/교체 및 열람 확인 버튼 없음.
- 가상 자료 시안과 계획 문서만 변경했다. 제품 기능 개발·실제 파일 업로드·배포는 진행하지 않았다.
